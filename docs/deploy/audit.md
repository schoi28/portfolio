# 감사와 규정 준수

차량 소프트웨어 배포는 기록이 남아야 합니다. 누가 무엇을 승인했고, 어떤 판단으로 배포했는지를 나중에 설명할 수 있어야 합니다.

## 승인 워크플로

조직 설정에 따라 특정 작업에 승인이 필요합니다.

| 작업 | 기본 설정 | 조정 가능 |
| --- | --- | --- |
| 캠페인 생성 | 승인 불필요 | 필요로 변경 가능 |
| 프로덕션 배포 시작 | 1인 승인 | 2인까지 확대 가능 |
| 게이트 중지 후 재개 | 1인 승인 | 필수. 해제 불가 |
| 롤백 실행 | 1인 승인 | 2인까지 확대 가능 |
| 긴급 중단 | 승인 불필요 | 사후 기록만 |

긴급 중단에 승인을 요구하지 않는 이유는 안전 조치의 지연을 막기 위해서입니다. 대신 실행 후 24시간 안에 사유를 보완 입력해야 합니다.

### 승인 요청하기

1. 승인이 필요한 작업을 실행하면 승인 요청 화면이 표시됩니다.
2. 승인자를 선택합니다. 자기 자신은 선택할 수 없습니다.
3. 요청 사유를 입력합니다.
4. **요청**을 선택합니다.

승인자에게 알림이 전송되며, 승인되면 작업이 자동으로 실행됩니다.

### 승인 대기 중 상태

| 상태 | 의미 |
| --- | --- |
| 승인 대기 | 요청됨. 아직 처리되지 않음 |
| 승인됨 | 작업이 실행됨 |
| 반려됨 | 승인자가 거부. 사유가 함께 기록됨 |
| 만료됨 | 24시간 내 처리되지 않음 |

만료된 요청은 다시 요청해야 합니다.

## 감사 로그 조회

**감사 > 로그**에서 조회합니다.

### 기록되는 항목

| 분류 | 예시 |
| --- | --- |
| 캠페인 | 생성, 수정, 시작, 중지, 재개, 종료 |
| 패키지 | 업로드, 서명 검증 결과, 삭제 |
| 타깃 그룹 | 생성, 조건 변경, 제외 목록 변경 |
| 롤백 | 요청, 승인, 실행, 완료 |
| 권한 | 사용자 추가·제거, 역할 변경 |
| 설정 | 게이트 기본값 변경, 승인 정책 변경 |

각 기록에는 수행자, 시각, 대상, 변경 전후 값, 입력한 사유가 포함됩니다.

### 검색과 내보내기

1. 기간, 수행자, 대상 유형으로 필터링합니다.
2. **내보내기**를 선택해 CSV로 받습니다.

내보내기는 최대 12개월 범위까지 가능합니다. 그보다 오래된 기록은 보관 시스템에서 별도로 요청해야 합니다.

:::note
감사 로그는 수정하거나 삭제할 수 없습니다. 잘못된 기록이 있다면 정정 사유를 새 기록으로 남기는 방식으로 처리합니다.
:::

## 릴리스 기록 보관

배포 하나당 아래 자료가 하나의 묶음으로 보관됩니다.

| 항목 | 보관 기간 |
| --- | --- |
| 패키지 메타데이터와 서명 정보 | 10년 |
| 캠페인 설정 (타깃 그룹, 게이트 기준) | 10년 |
| 배포 결과 (차량별 설치 상태) | 10년 |
| 승인 기록 | 10년 |
| 사후 분석 리포트 | 10년 |
| 원본 패키지 파일 | 5년 |

보관 기간이 긴 이유는 차량의 사용 수명이 길기 때문입니다. 출고 후 여러 해가 지난 차량의 문제를 조사할 때, 그 시점에 어떤 소프트웨어가 어떤 경로로 설치되었는지 확인할 수 있어야 합니다.

### 릴리스 기록 내려받기

1. **감사 > 릴리스 기록**을 선택합니다.
2. 캠페인을 선택합니다.
3. **패키지 내려받기**를 선택합니다.

생성에는 몇 분이 걸립니다. 준비되면 알림이 오며, 다운로드 링크는 7일간 유효합니다.

## 규제 대응 시 자주 요청되는 자료

| 요청 | 어디서 얻는가 |
| --- | --- |
| 특정 차량의 소프트웨어 이력 | **감사 > 차량 이력**에서 VIN으로 조회 |
| 특정 배포의 승인 경로 | 릴리스 기록의 승인 기록 |
| 배포 중단 사유와 조치 | 사후 분석 리포트 |
| 대상에서 제외된 차량과 사유 | 타깃 그룹의 제외 목록 변경 이력 |

:::note
이 문서는 포트폴리오용으로 창작한 가상 제품의 문서입니다. 특정 국가나 지역의 실제 규제 요건을 반영하지 않습니다.
:::
