# 배포 준비하기

캠페인을 만들기 전에 정해야 하는 네 가지를 다룹니다. **패키지 올리고 서명 확인하기, 호환성 규칙 정하기, 대상 차량 고르기, 설치 사전 조건 정하기**입니다. 전체 30분에서 1시간이 걸립니다.

여기서 잘못 정하면 배포가 시작된 뒤에는 되돌리기 어렵습니다. 배포를 시작하기 전에 [배포 전 점검하기](#배포-전-점검하기)의 확인 항목을 **하나씩 모두 확인하십시오.**

## 패키지 업로드하고 서명 검증하기

### 업로드하기

:::info[주의]
릴리스 노트는 최종 사용자가 읽습니다. 내부 이슈 번호나 코드명을 쓰지 마십시오.
:::

1. **패키지 > 새 패키지**를 선택합니다.
2. `.vpk` 파일을 업로드합니다. 최대 4GB까지 지원합니다.
3. 릴리스 노트를 입력합니다. 여기에 입력한 내용이 차량 소유자의 앱에 표시됩니다.

### 서명 검증

업로드 직후 자동으로 실행됩니다. 서명은 두 단계로 검증됩니다.

| 단계 | 검증 내용 | 실패 시 |
| --- | --- | --- |
| 1차 (콘솔) | 등록된 빌드 키로 서명되었는지 | 업로드 거부 |
| 2차 (차량) | 차량이 설치 직전 다시 검증 | 해당 차량만 설치 실패 |

2차 검증은 콘솔에서 통과한 패키지도 차량에서 실패할 수 있음을 뜻합니다. 이는 전송 중 손상을 잡기 위한 장치입니다.

## 호환성 규칙 정의하기

어떤 상태의 차량이 이 패키지를 받을 수 있는지 정의합니다. 타깃 그룹과 별개로, 패키지 자체에 붙는 조건입니다.

| 규칙 | 예시 | 위반 시 동작 |
| --- | --- | --- |
| 최소 현재 버전 | `>= 2026.6.0` | 대상에서 제외 |
| 최대 현재 버전 | `< 2026.9.0` | 대상에서 제외 |
| 하드웨어 리비전 | `rev_b` 이상 | 대상에서 제외 |
| 선행 패키지 | `pkg_2026_8_1` 설치 필요 | 대기 상태로 보류 |

**선행 패키지**는 순서대로 설치해야 하는 경우에 사용합니다. 예를 들어 부품 펌웨어가 먼저 올라가야 하는 소프트웨어 업데이트라면, 펌웨어 패키지를 선행으로 지정합니다. 조건을 만족하지 않는 차량은 실패가 아니라 **대기** 상태가 되며, 선행 패키지가 설치되면 자동으로 진행됩니다.

:::warning[경고]
호환성 규칙을 지정하지 않으면 모든 버전의 차량이 대상이 됩니다. 오래된 버전에서 곧바로 최신 버전으로 건너뛰는 설치는 검증되지 않은 경로일 가능성이 높습니다.
:::

## 타깃 그룹 만들기

### 조건 조합하기

조건은 AND로 결합됩니다. 여러 조건을 지정할수록 대상이 좁아집니다.

| 조건 | 값의 예 | 비고 |
| --- | --- | --- |
| 차종 | `Hanul EV Sedan` | 필수 |
| 현재 버전 | `2026.8.2` | 여러 개 지정 가능 |
| 지역 | `KR`, `US` | 규제 차이가 있는 경우 분리 |
| 하드웨어 구성 | `sensor_kit: installed` | 검증 차량만 대상으로 할 때 |
| 차량 목록 | VIN 직접 입력 | 소수 차량 대상 테스트용 |

### 제외 목록

특정 차량을 대상에서 빼야 할 때 사용합니다.

1. 타깃 그룹 편집 화면에서 **제외 목록**을 선택합니다.
2. VIN을 입력하거나 CSV로 업로드합니다.

제외 목록은 조건보다 우선합니다. 조건에 맞아도 제외 목록에 있으면 배포되지 않습니다. 사고 조사 중인 차량이나 특수 목적 차량을 빼는 데 사용합니다.

### 대상 규모 확인하기

**미리보기**는 현재 시점의 대상 차량 수를 보여줍니다. 이 숫자는 시간이 지나면서 달라집니다. 다른 캠페인으로 버전이 바뀌면 조건에서 벗어나기 때문입니다.

## 사전 조건 설정하기

차량이 설치를 시작하기 위해 만족해야 하는 상태입니다.

| 사전 조건 | 기본값 | 조정 가능 범위 |
| --- | --- | --- |
| 주차 상태 | 필수 | 해제 불가 |
| 구동 배터리 잔량 | 30% 이상 | 20~60% |
| 보조 배터리 잔량 | 40% 이상 | 30~70% |
| 네트워크 | 필수 | 해제 불가 |
| 시동 꺼짐 | 존 ECU만 필수 | 대상 유형에 따라 자동 |
| 설치 허용 시간대 | 제한 없음 | 시간대 지정 가능 |

### 설치 허용 시간대

야간에만 설치되도록 제한할 수 있습니다.

- 차량의 현지 시각을 기준으로 판정합니다.
- 시간대를 좁게 잡으면 배포 완료까지 걸리는 기간이 길어집니다.
- 오래 걸리는 캠페인은 그만큼 오래 지켜봐야 합니다.

:::note[참고]
사전 조건을 엄격하게 잡을수록 실패율은 낮아지지만 배포 속도는 느려집니다. 긴급 보안 패치라면 배터리 조건을 낮추고, 대규모 기능 업데이트라면 조건을 높이는 식으로 조정합니다.
:::

## 배포 전 점검하기

시작 버튼을 누르기 전에 확인하십시오.

| 확인 항목 | 확인 방법 |
| --- | --- |
| 패키지 서명 검증 통과 | 패키지 상태가 **검증 완료** |
| 릴리스 노트가 사용자에게 적절한가 | 내부 용어 없음 |
| 대상 규모가 예상과 일치하는가 | 미리보기 숫자 |
| 제외 목록이 반영되었는가 | 제외 목록 건수 |
| 롤아웃 1단계가 충분히 작은가 | 1% 이하 권장 |
| 게이트 기준이 설정되었는가 | 성공률·오류율 값 |
| 롤백 패키지가 준비되었는가 | 이전 버전 패키지가 검증 완료 상태 |

마지막 항목이 특히 중요합니다. 롤백은 이전 버전 패키지가 있어야 실행할 수 있습니다.
