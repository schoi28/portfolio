# 문제에 대응하기

배포 중 문제가 발생했을 때 판단하고 조치하는 절차입니다.

:::note
이 장은 다른 장을 읽지 않아도 이해할 수 있도록 필요한 개념을 다시 설명합니다. 사고 상황에서 문서를 처음부터 읽을 수 없기 때문입니다.
:::

## 먼저 판단할 것: 멈출 것인가, 되돌릴 것인가

세 가지 선택지가 있습니다. 영향 범위와 되돌리기 비용이 다릅니다.

| 조치 | 하는 일 | 이미 설치된 차량 | 사용 시점 |
| --- | --- | --- | --- |
| 일시 중지 | 새 배포만 멈춤 | 그대로 둠 | 원인 조사가 필요할 때 |
| 롤백 | 이전 버전으로 되돌림 | 되돌림 | 설치된 버전에 문제가 확인되었을 때 |
| 긴급 중단 | 진행 중인 설치까지 즉시 중단 | 그대로 둠 | 안전 문제가 의심될 때 |

### 판단 기준

| 상황 | 권장 조치 |
| --- | --- |
| 실패율이 높지만 설치된 차량은 정상 | 일시 중지 후 실패 코드 분석 |
| 설치된 차량에서 기능 이상 보고 | 롤백 |
| 설치된 차량에서 주행 관련 이상 보고 | 긴급 중단 후 롤백 |
| 원인을 모르겠고 영향이 커지는 중 | 긴급 중단 |

판단이 서지 않으면 멈추는 쪽을 선택하십시오. 멈춘 배포는 다시 시작할 수 있지만, 확대된 영향은 되돌리는 데 시간이 걸립니다.

## 롤백 절차

### 사전 확인

:::warning
롤백은 이전 버전 패키지가 검증 완료 상태로 등록되어 있어야 실행할 수 있습니다. 등록되어 있지 않으면 롤백을 시작할 수 없습니다.
:::

1. **패키지** 목록에서 이전 버전이 **검증 완료** 상태인지 확인합니다.
2. 롤백 대상 범위를 정합니다.

| 범위 | 설명 |
| --- | --- |
| 이 캠페인 전체 | 이 캠페인으로 설치된 모든 차량 |
| 특정 단계 | 예를 들어 2단계에서 설치된 차량만 |
| 차량 목록 지정 | VIN 목록으로 지정 |

### 실행

1. 캠페인 상세 화면에서 **롤백**을 선택합니다.
2. 이전 버전 패키지를 선택합니다.
3. 롤백 범위를 선택합니다.
4. 사유를 입력합니다. 필수 항목입니다.
5. 승인자를 지정합니다. 조직 설정에 따라 2인 승인이 필요할 수 있습니다.
6. **롤백 시작**을 선택합니다.

### 롤백에 걸리는 시간

| 대상 | 소요 시간 | 이유 |
| --- | --- | --- |
| 중앙 연산 장치 | 차량당 5~10분 | 이전 파티션으로 전환 후 재부팅 |
| 존 ECU | 차량당 30~60분 | 이전 펌웨어를 다시 기록해야 함 |

롤백도 설치와 같은 사전 조건을 요구합니다. 차량이 주차 상태가 되어야 진행되므로, 전체 완료까지는 배포와 비슷한 기간이 걸립니다.

:::caution
롤백 중에 원래 캠페인을 재개하지 마십시오. 같은 차량에 설치와 롤백이 번갈아 적용되어 상태를 추적할 수 없게 됩니다.
:::

## 긴급 중단

가장 강한 조치입니다. 진행 중인 다운로드와 설치를 즉시 중단합니다.

1. 캠페인 상세 화면에서 **긴급 중단**을 선택합니다.
2. 확인 문구를 입력합니다.
3. 사유를 입력합니다.

:::warning
긴급 중단한 캠페인은 재개할 수 없습니다. 다시 배포하려면 새 캠페인을 만들어야 합니다. 설치가 진행 중이던 차량은 자동으로 이전 버전으로 복구됩니다.
:::

긴급 중단은 즉시 전파되지만, 통신되지 않는 차량에는 다음 접속 시점에 적용됩니다.

## 실패 코드 해석하기

### 차량 측 실패

| 코드 | 의미 | 대응 |
| --- | --- | --- |
| `E_PRECOND_BATTERY` | 배터리 잔량 부족 | 정상. 조건 충족 시 자동 재시도 |
| `E_PRECOND_PARKED` | 주차 상태 아님 | 정상. 자동 재시도 |
| `E_DOWNLOAD_TIMEOUT` | 다운로드 시간 초과 | 통신 환경 문제. 자동 재시도 |
| `E_SIGNATURE_INVALID` | 서명 검증 실패 | 조사 필요. 패키지 전송 손상 의심 |
| `E_INSTALL_ABORTED` | 설치 중 중단됨 | 사용자가 시동을 걸었을 가능성 |
| `E_BOOT_FAILED` | 설치 후 부팅 실패 | **즉시 조사.** 자동 롤백됨 |
| `E_INCOMPATIBLE_HW` | 하드웨어 비호환 | 호환성 규칙 재검토 |

`E_PRECOND_*`와 `E_DOWNLOAD_TIMEOUT`은 정상 범주입니다. 실패율에 포함되지만 조사 대상이 아닙니다. 게이트 판정 시 이들을 제외한 **실질 실패율**을 함께 확인하십시오.

### 조사가 필요한 코드

`E_SIGNATURE_INVALID`, `E_BOOT_FAILED`, `E_INCOMPATIBLE_HW` 세 가지는 발생 즉시 조사합니다. 비율이 낮아도 마찬가지입니다.

## 사후 분석 리포트 작성하기

캠페인이 종료되거나 중단된 뒤 작성합니다.

1. 캠페인 상세 화면에서 **사후 분석 리포트 생성**을 선택합니다.
2. 자동으로 채워지는 항목을 확인합니다.

| 자동 수집 항목 | 내용 |
| --- | --- |
| 타임라인 | 시작·단계 전환·중지·롤백 시각 |
| 지표 | 단계별 성공률·실패 코드 분포 |
| 조치 이력 | 누가 언제 무엇을 했는지 |
| 사유 기록 | 중지·재개·롤백 시 입력한 사유 |

3. 아래 항목을 직접 작성합니다.

- 무엇이 문제였는가
- 왜 사전에 발견하지 못했는가
- 다음에 무엇을 바꿀 것인가

4. **확정**을 선택합니다. 확정한 리포트는 수정할 수 없으며 감사 기록에 포함됩니다.
