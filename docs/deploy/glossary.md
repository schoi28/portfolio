# 용어 찾아보기

이 문서에 나오는 용어와 약어입니다. 업무 도구에는 익숙하지만 차량 소프트웨어 분야는 처음인 독자를 기준으로 풀어 썼습니다.

상태 값과 실패 코드의 목록은 [레퍼런스 찾아보기](./reference.md)에 있습니다. 여기에는 **개념어**만 모았습니다.

## 배포

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| OTA | Over-The-Air | 차량을 정비소에 들이지 않고 무선으로 소프트웨어를 갱신하는 방식 |
| 패키지 | package | 차량에 설치되는 소프트웨어 묶음. 확장자는 `.vpk`입니다 |
| 캠페인 | campaign | 하나의 패키지를 정해진 대상에 배포하는 단위 |
| 타깃 그룹 | target group | 배포 대상 차량의 조건. 차종·하드웨어 구성·현재 버전으로 정의합니다 |
| 호환성 규칙 | compatibility rule | 어느 버전에서 어느 버전으로 올릴 수 있는지를 정한 조건 |
| 롤아웃 | rollout | 대상을 단계적으로 넓혀 가는 배포 방식 |
| 롤아웃 단계 | rollout stage | 한 번에 배포할 비율의 구간 (예: 1단계 1%) |
| 게이트 | gate | 다음 단계로 넘어갈지 판정하는 기준. 성공률과 오류율로 정의합니다 |
| 카나리 | canary | 전체 배포 전에 소수에게 먼저 배포해 문제를 찾는 방식. 1단계가 여기에 해당합니다 |
| 롤백 | rollback | 배포한 소프트웨어를 이전 버전으로 되돌리는 것 |
| 긴급 중단 | abort | 캠페인을 즉시 끝내는 것. **재개할 수 없습니다** |
| 일시 중지 | pause | 새 차량으로의 배포만 멈추는 것. 진행 중인 설치는 계속됩니다 |

## 차량과 설치

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 사전 조건 | precondition | 설치를 시작하기 위해 차량이 만족해야 하는 상태 (주차, 배터리 잔량, 통신 가능) |
| 설치 허용 시간대 | installation window | 설치를 수행해도 되는 시간 범위. 보통 심야로 잡습니다 |
| CCU | Central Computing Unit | 차량의 중앙 연산 장치. 클라우드와 통신하는 유일한 지점입니다 |
| 존 ECU | zonal ECU | 차량을 구역별로 나눠 담당하는 제어기. 부품 펌웨어의 배포 대상입니다 |
| 부품 펌웨어 | component firmware | 도어·공조 같은 개별 부품의 제어 소프트웨어. 본체 소프트웨어보다 설치가 오래 걸립니다 |
| A/B 파티션 | A/B partition | 저장 공간을 둘로 나눠 한쪽에 설치하고 다음 부팅에 전환하는 방식. 실패 시 즉시 되돌릴 수 있습니다 |

## 보안과 감사

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 서명 검증 | signature verification | 패키지가 정당한 발행자가 만든 것이고 변조되지 않았음을 확인하는 절차 |
| Uptane | — | 차량 소프트웨어 배포의 보안 프레임워크. 서명 체계의 국제 표준입니다 |
| 감사 로그 | audit log | 누가 언제 무엇을 했는지 기록한 이력. **수정하거나 삭제할 수 없습니다** |
| 승인 워크플로 | approval workflow | 배포 전에 책임자의 승인을 받도록 강제하는 절차 |
| 추적성 | traceability | 어느 차량에 어느 버전이 언제 설치됐는지 되짚을 수 있는 성질 |

## 지표

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 성공률 | success rate | 설치를 시도한 차량 중 완료한 비율 |
| 오류율 | error rate | 설치를 시도한 차량 중 실패한 비율 |
| 최소 표본 수 | minimum sample size | 게이트를 판정하기 위해 필요한 최소 차량 대수. 적으면 비율이 요동칩니다 |
| 자동 재시도 | automatic retry | 일시적 실패로 분류된 경우 시스템이 다시 시도하는 동작 |
| 도달률 | reach rate | 배포 대상 중 실제로 통신이 닿은 차량의 비율 |
