# 롤아웃 운영하기

배포를 시작한 뒤 단계를 확대하며 상태를 감시하는 과정입니다.

## 단계적 확대 전략 세우기

![롤아웃이 단계적으로 확대되는 과정](/img/deploy-rollout-stages.svg)

한 번에 전체 차량에 배포하지 않는 이유는 단순합니다. 문제를 발견했을 때 영향받은 차량 수를 줄이기 위해서입니다.

### 유형별 권장 단계

| 배포 유형 | 권장 단계 | 이유 |
| --- | --- | --- |
| 기능 업데이트 | 1% → 10% → 50% → 100% | 사용자 반응을 볼 시간이 필요 |
| 버그 수정 | 5% → 50% → 100% | 이미 검증된 변경이므로 빠르게 |
| 보안 긴급 패치 | 10% → 100% | 노출 시간을 줄이는 것이 우선 |
| 부품 펌웨어 | 0.5% → 5% → 25% → 100% | 되돌리기가 가장 어려움 |

부품 펌웨어를 가장 조심스럽게 다루는 이유는 [개요 · 핵심 개념](./intro.md)에서 설명한 대로, 존 ECU 펌웨어는 차량이 완전히 정지한 상태에서만 적용되고 복구도 오래 걸리기 때문입니다.

### 단계별 대기 시간

각 단계는 최소 관찰 기간을 두는 것을 권장합니다.

| 단계 | 최소 관찰 기간 | 근거 |
| --- | --- | --- |
| 1단계 | 48시간 | 대상 차량이 주차 상태가 될 시간 필요 |
| 중간 단계 | 24시간 | 지연성 문제 발견 |
| 최종 단계 | — | 완료까지 모니터링 유지 |

48시간을 두는 이유는 설치가 주차 상태에서만 진행되기 때문입니다. 24시간만 관찰하면 아직 설치하지 않은 차량이 많아 성공률이 실제를 반영하지 않습니다.

## 게이트 기준 설정하기

게이트는 다음 단계로 넘어갈지 자동으로 판정하는 조건입니다.

| 지표 | 계산 방법 | 권장 기준 |
| --- | --- | --- |
| 성공률 | 설치 완료 ÷ (완료 + 실패) | 98% 이상 |
| 오류율 | 실패 ÷ 대상 | 2% 이하 |
| 부팅 실패율 | 설치 후 부팅 실패 ÷ 완료 | 0.1% 이하 |
| 롤백 발생률 | 자동 롤백 ÷ 완료 | 0.5% 이하 |

:::note
위 숫자는 예시입니다. 조직의 위험 허용 수준에 따라 정해야 하며, 배포 유형별로 다르게 잡는 것이 일반적입니다. 부품 펌웨어는 부팅 실패율 기준을 더 엄격하게 잡습니다.
:::

### 최소 표본 수

비율만으로 판정하면 대상이 적을 때 왜곡됩니다. 10대 중 1대가 실패하면 성공률이 90%가 되어 기준 미달로 잡힙니다.

- 게이트는 **최소 완료 건수**를 함께 지정합니다. 기본값은 50건입니다.
- 완료 건수가 최소 표본에 미치지 않으면 게이트는 판정을 보류하고 대기합니다.

## 모니터링 대시보드 읽는 법

캠페인 상세 화면에서 확인합니다.

| 영역 | 보는 방법 |
| --- | --- |
| 진행률 그래프 | 시간에 따른 완료 건수 누적. 기울기가 갑자기 꺾이면 조사 필요 |
| 상태 분포 | 다운로드 중·설치 대기·완료·실패의 비율 |
| 실패 코드 분포 | 어떤 원인이 많은지. 한 코드에 몰리면 공통 원인 |
| 지역별 분포 | 특정 지역에 실패가 몰리는지 |

### 주의해서 볼 신호

| 신호 | 가능한 원인 |
| --- | --- |
| 설치 대기가 줄지 않음 | 사전 조건이 너무 엄격함 |
| 다운로드에서 멈춤 | 패키지 크기 대비 통신 환경 문제 |
| 특정 실패 코드에 집중 | 패키지 또는 호환성 규칙 문제 |
| 부팅 실패가 조금씩 증가 | 특정 하드웨어 리비전과의 충돌 |

마지막 항목이 가장 위험합니다. 비율은 낮지만 대상이 늘수록 절대 수가 커집니다. 단계를 확대하기 전에 하드웨어 리비전별로 나눠서 확인하십시오.

## 일시 중지하고 재개하기

### 일시 중지

1. 캠페인 상세 화면에서 **일시 중지**를 선택합니다.
2. 사유를 입력합니다. 감사 로그에 기록됩니다.

일시 중지하면 새로운 차량에 배포가 시작되지 않습니다. 이미 다운로드나 설치가 진행 중인 차량은 그대로 완료됩니다.

:::caution
일시 중지는 진행 중인 설치를 멈추지 않습니다. 즉시 모든 동작을 멈춰야 한다면 [긴급 중단](./incident-response.md#긴급-중단)을 사용하십시오.
:::

### 재개

1. **재개**를 선택합니다.
2. 재개할 단계를 선택합니다. 같은 단계에서 이어가거나, 이전 단계로 되돌릴 수 있습니다.

게이트에 의해 중지된 캠페인을 재개하려면 사유 입력이 필수입니다. "왜 기준 미달에도 계속하기로 판단했는가"가 사후 분석의 핵심 자료가 됩니다.

## 캠페인 종료하기

모든 단계가 완료되면 상태가 **완료**로 바뀝니다. 다만 대상 차량 전부가 설치를 마쳤다는 뜻은 아닙니다.

| 상황 | 처리 |
| --- | --- |
| 장기간 주차되지 않은 차량 | 조건을 만족할 때까지 대기 상태 유지 |
| 통신되지 않는 차량 | 최대 90일간 재시도 |
| 90일 경과 | 대상에서 자동 제외. 다음 캠페인에서 처리 |

**미완료 차량 목록**을 내려받아 다음 캠페인의 타깃 그룹으로 쓸 수 있습니다.
