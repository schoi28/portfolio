# 카메라 장착하기

CM-20 카메라 4대를 전방·후방·좌측·우측에 장착합니다. 약 60분이 걸립니다.

:::danger[위험]
A필러 작업 시 커튼 에어백 전개 경로를 침범하지 마십시오. 케이블은 순정 하네스와 같은 경로로 고정합니다.
:::

## 공통 사항

| 항목 | 값 |
| --- | --- |
| 장착면 온도 | 15~35 °C |
| 접착 경화 시간 | 24시간 (완전 경화 72시간) |
| 케이블 커넥터 | FAKRA 동축, 색상으로 위치 구분 |

각 카메라의 케이블 커넥터에는 색상 표시가 있습니다. 잘못 연결하면 위치가 뒤바뀐 채로 인식됩니다.

| 카메라 | 커넥터 색상 | 인터페이스 박스 포트 |
| --- | --- | --- |
| C1 전방 | 파란색 | `CAM1` |
| C2 후방 | 초록색 | `CAM2` |
| C3 좌측 | 노란색 | `CAM3` |
| C4 우측 | 흰색 | `CAM4` |

## C1 전방 카메라

앞유리 상단 중앙, 룸미러 뒤쪽에 장착합니다.

:::info[주의]
와이퍼 범위 밖에 장착하면 비 오는 날 시야가 가려집니다. 청소 알림이 반복해서 발생하는 원인이 됩니다.
:::

1. 장착 위치를 탈지제로 닦고 건조시킵니다.
2. 브래킷의 보호 필름을 벗기고 앞유리 안쪽에 부착합니다.
3. 카메라를 브래킷에 밀어 넣습니다. **딸깍** 소리가 나면 고정된 것입니다.
4. 카메라 시야가 와이퍼 작동 범위 **안**에 있는지 확인합니다.

| 확인 항목 | 기준 |
| --- | --- |
| 앞유리 상단에서의 거리 | 40~60 mm |
| 차량 중심선과의 편차 | ± 10 mm |
| 와이퍼 작동 범위 | 시야 전체가 범위 안 |
| 룸미러 간섭 | 최대 각도에서 접촉 없음 |

## C2 후방 카메라

트렁크 리드 상단 중앙에 장착합니다.

:::warning[경고]
힌지 구간의 케이블 여유가 부족하면 개폐를 반복하다 단선됩니다. 완전 개방 상태에서 최소 30 mm의 여유가 있어야 합니다.
:::

1. 장착 위치를 탈지제로 닦습니다.
2. 브래킷을 부착하고 카메라를 끼웁니다.
3. 케이블을 트렁크 리드 힌지의 그로밋을 통해 실내로 통과시킵니다.
4. 트렁크를 **완전히 열고 닫으며** 케이블이 당겨지지 않는지 확인합니다.

## C3·C4 측면 카메라

좌우 사이드미러 하단에 장착합니다. 절차는 좌우가 동일합니다.

1. 사이드미러 하단 커버를 분리합니다.
2. 카메라 브래킷을 미러 하우징 안쪽에 볼트 2개로 고정합니다. 토크는 **2.5 N·m**입니다.
3. 카메라 렌즈가 하방 45°를 향하게 조정합니다.
4. 케이블을 미러 하네스와 함께 도어 내부로 통과시킵니다.
5. 커버를 복원합니다.

| 확인 항목 | 기준 |
| --- | --- |
| 렌즈 각도 | 하방 45° ± 5° |
| 도어 개폐 간섭 | 최대 개방 시 접촉 없음 |
| 미러 접힘 동작 | 전동 접힘 시 케이블 간섭 없음 |

전동 접이식 미러라면 접힘 동작을 5회 반복해 케이블이 씹히지 않는지 확인하십시오.

## 케이블 정리

1. 모든 카메라 케이블을 트렁크의 인터페이스 박스 위치로 모읍니다.
2. 케이블 타이로 순정 하네스에 **300 mm 간격**으로 고정합니다.
3. 커넥터 근처에는 드립 루프를 만듭니다.

:::info[주의]
케이블을 팽팽하게 당겨 고정하지 마십시오. 차체 진동이 커넥터에 그대로 전달됩니다.
:::

## 확인 항목

| 확인 | 기준 |
| --- | --- |
| 커넥터 색상과 포트 일치 | 표 참조 |
| C1 와이퍼 범위 | 시야 전체가 범위 안 |
| C2 힌지 여유 | 완전 개방 시 30 mm 이상 |
| C3·C4 렌즈 각도 | 하방 45° ± 5° |
| 도어·트렁크 개폐 | 간섭 없음 |
| 케이블 고정 간격 | 300 mm 이하 |
| 렌즈 청결 | 지문·이물질 없음 |
