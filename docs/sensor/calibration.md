# 캘리브레이션하기

각 센서가 차량 기준으로 정확히 어디를 보고 있는지 계산해 등록하는 과정입니다. [정적 캘리브레이션](#정적-캘리브레이션-수행하기)과 [동적 캘리브레이션](#동적-캘리브레이션-수행하기)을 순서대로 수행합니다. 약 60분이 걸립니다.

## 캘리브레이션이 필요한 이유 이해하기

장착 과정에서 아무리 정밀하게 맞춰도 밀리미터 단위의 오차가 남습니다. 라이다와 카메라가 같은 물체를 서로 다른 위치로 인식하면 두 데이터를 합칠 수 없습니다.

캘리브레이션은 이 오차를 측정해 보정값으로 등록합니다. 보정할 수 있는 범위에는 한계가 있으므로, 장착 단계의 허용 오차를 지키는 것이 전제입니다.

:::info[주의]
장착 허용 오차를 벗어난 상태에서는 캘리브레이션이 실패합니다. 소프트웨어로 보정 가능한 범위는 각 축 **±0.5°** 이내입니다.
:::

## 정적 캘리브레이션 수행하기

### 작업 환경 조건

:::info[주의]
타이어 공기압이 규정과 다르면 차체 높이가 달라져 결과가 부정확해집니다. 아래 표를 확인하기 전에 공기압부터 맞추십시오.
:::

| 항목 | 기준 |
| --- | --- |
| 바닥 | 수평. 기울기 0.5% 이하 |
| 조도 | 300 lux 이상, 균일 |
| 공간 | 차량 전방 8 m, 좌우 4 m 이상 |
| 주변 반사물 | 유리·거울면 없음 |
| 차량 상태 | 짐을 비운 상태, 타이어 공기압 규정값 |

### 타깃 보드 배치

![정적 캘리브레이션 시 타깃 보드 배치](/img/sensor-calibration-layout.svg)

| 타깃 | 위치 | 차량 기준 거리 | 허용 오차 |
| --- | --- | --- | --- |
| A | 전방 좌측 | 3.0 m | ± 5 cm |
| B | 전방 우측 | 3.0 m | ± 5 cm |
| C | 정면 | 6.0 m | ± 5 cm |

1. 차량을 지정 위치에 정면으로 정렬합니다. 좌우 편차는 **± 2 cm** 이내입니다.
2. 타깃 보드를 표의 위치에 세웁니다.
3. 각 보드가 지면과 **수직**인지 수평계로 확인합니다. 허용 오차는 ± 1°입니다.
4. 보드의 중심 높이를 **1.2 m**에 맞춥니다.

### 실행하기

1. 노트북을 `DIAG` 포트에 연결하고 `http://192.168.10.1`에 접속합니다.
2. **캘리브레이션 > 정적 캘리브레이션**을 선택합니다.
3. 차종과 브래킷 코드를 입력합니다.
4. **시작**을 선택합니다.

측정은 약 5분이 걸립니다. 이 시간 동안 차량과 타깃 보드를 움직이지 마십시오. 사람도 카메라 시야에서 벗어나 있어야 합니다.

### 합격 기준

| 항목 | 합격 기준 | 의미 |
| --- | --- | --- |
| 라이다 각도 편차 | 0.30° 이하 | 계산된 보정각의 크기 |
| 카메라 재투영 오차 | 0.50 px 이하 | 예측 위치와 실제 위치의 차이 |
| 라이다-카메라 정합 오차 | 0.60° 이하 | 두 센서 간 일치도 |
| 타깃 검출률 | 100% | 3개 보드 모두 검출 |

모든 항목이 합격이면 결과가 자동으로 저장되고, 상태가 `valid`로 바뀝니다.

## 동적 캘리브레이션 수행하기

정적 캘리브레이션만으로는 주행 중 발생하는 진동과 자세 변화를 반영하지 못합니다. 실제 주행으로 보완합니다.

### 주행 조건

| 항목 | 기준 |
| --- | --- |
| 주행 거리 | 최소 15 km |
| 속도 구간 | 40~80 km/h 구간이 절반 이상 |
| 도로 | 직선 구간과 곡선 구간 모두 포함 |
| 차선 | 차선 표시가 뚜렷한 도로 |
| 날씨 | 맑음 또는 흐림. 강우·강설 시 불가 |
| 시간대 | 주간 |

### 실행하기

:::warning[경고]
주행 중 노트북을 조작하지 마십시오. 2인 1조로 작업하고, 조작은 동승자가 수행합니다.
:::

1. **캘리브레이션 > 동적 캘리브레이션**을 선택하고 **시작**을 선택합니다.
2. 조건을 만족하는 도로를 주행합니다.
3. 진행률은 차량 화면 또는 노트북에서 확인할 수 있습니다.
4. 100%가 되면 자동으로 계산이 시작됩니다.

주행 조건을 만족하지 못하면 진행률이 오르지 않습니다. 예를 들어 정체 구간에서는 속도 조건을 만족하지 못해 거리만 늘고 진행률은 그대로입니다.

### 합격 기준

| 항목 | 합격 기준 |
| --- | --- |
| 자세 추정 수렴 | 표준편차 0.15° 이하 |
| 차선 정합 오차 | 0.25 m 이하 |
| 유효 데이터 비율 | 60% 이상 |

## 결과 해석하기

### 합격한 경우

결과가 차량에 저장되고 API로 조회할 수 있습니다. 조회 방법은 [VELA Vehicle API · 센서 상태 조회하기](../api/sensors.md)를 참고하십시오.

| 상태 | 의미 |
| --- | --- |
| `valid` | 유효함 |
| `stale` | 90일 경과 또는 500 km 이상 주행. 재수행 권장 |

### 실패한 경우

| 실패 항목 | 가능한 원인 | 조치 |
| --- | --- | --- |
| 타깃 검출률 미달 | 보드 위치·조도 문제 | 배치와 조도를 다시 확인합니다 |
| 라이다 각도 편차 초과 | 장착 기울기 불량 | [라이다 장착하기](./lidar-mount.md) 3단계를 다시 수행합니다 |
| 카메라 재투영 오차 초과 | 카메라 각도 불량 또는 렌즈 오염 | 렌즈를 닦고 각도를 재확인합니다 |
| 정합 오차 초과 | 카메라 위치 뒤바뀜 | [초기 점검](./power-check.md#카메라-위치-매핑-확인)을 다시 확인합니다 |
| 자세 추정 미수렴 | 주행 조건 부족 | 조건에 맞는 도로에서 재주행합니다 |

:::info[주의]
캘리브레이션에 실패한 상태로 차량을 운용하지 마십시오. 센서 데이터가 부정확하면 이를 사용하는 모든 기능의 신뢰도가 떨어집니다.
:::

## 다시 캘리브레이션해야 하는 경우

| 상황 | 필요한 캘리브레이션 |
| --- | --- |
| 센서를 떼었다가 다시 붙임 | 정적 + 동적 |
| 사고로 차체가 변형됨 | 정적 + 동적 |
| 앞유리를 교체함 | 정적 + 동적 (전방 카메라) |
| 사이드미러를 교체함 | 정적 + 동적 (해당 측면 카메라) |
| 타이어를 다른 규격으로 교체함 | 동적 |
| 상태가 `stale`로 바뀜 | 동적 |
| 서스펜션을 교체함 | 정적 + 동적 |
