# 점검하고 관리하기

센서는 표면 상태에 성능이 크게 좌우됩니다. 정기 점검과 청소가 필요합니다.

## 점검 주기

| 항목 | 주기 | 소요 시간 |
| --- | --- | --- |
| 렌즈·광학창 청소 | 2주 또는 오염 알림 발생 시 | 10분 |
| 커넥터 체결 확인 | 3개월 | 15분 |
| 브래킷 토크 확인 | 6개월 | 20분 |
| 실런트 상태 확인 | 6개월 | 10분 |
| 캘리브레이션 상태 확인 | 3개월 | 5분 |
| 전체 진단 실행 | 6개월 | 15분 |

검증 차량을 험로나 우천 환경에서 자주 운용한다면 주기를 절반으로 줄이십시오.

## 청소 방법

### 준비물

| 항목 | 규격 |
| --- | --- |
| 극세사 천 | 보풀이 없는 것 |
| 렌즈 세정액 | 광학용 중성 세정액 |
| 블로어 | 압축가스 캔 또는 수동 블로어 |

:::danger[위험]
청소 전 반드시 전원을 차단하십시오. 동작 중에는 확대경이나 확대 기능이 있는 카메라로 광학창을 들여다보지 마십시오(Class 1M).
:::

### 절차

:::warning[경고]
알코올, 아세톤, 암모니아가 든 세정제를 사용하지 마십시오. 광학 코팅이 손상되면 부품을 교체해야 합니다. 고압 세척기를 센서에 직접 분사하는 것도 금지입니다.
:::

1. 시동을 끄고 5분 이상 기다립니다. 센서 표면이 뜨거울 수 있습니다.
2. 블로어로 표면의 마른 먼지를 불어냅니다.
3. 극세사 천에 세정액을 소량 묻힙니다. 표면에 직접 뿌리지 마십시오.
4. 한 방향으로 부드럽게 닦습니다. 원을 그리며 문지르지 마십시오.
5. 마른 부분으로 남은 세정액을 닦아냅니다.

### 청소 후 확인

1. 시동을 걸고 [초기 진단](./power-check.md#4-초기-진단-실행하기)을 실행합니다.
2. 센서 상태가 `ok`로 회복되었는지 확인합니다.

청소 후에도 `degraded`가 유지되면 표면 손상 또는 내부 문제일 수 있습니다.

## 커넥터와 브래킷 점검

### 커넥터

1. 각 커넥터의 잠금 상태를 손으로 확인합니다.
2. 커넥터 주변에 수분이나 부식이 있는지 육안으로 확인합니다.
3. 케이블 고정 타이가 끊어진 곳이 없는지 확인합니다.

부식이 보이면 커넥터를 분리해 건조시키고, 접점 부식이 진행된 경우 케이블을 교체합니다.

### 브래킷 토크

| 대상 | 규정 토크 | 재조임 기준 |
| --- | --- | --- |
| 라이다 브래킷 | 18 N·m ± 2 | 16 N·m 미만이면 재조임 |
| 라이다 본체 | 9 N·m ± 1 | 8 N·m 미만이면 재조임 |
| 카메라 측면 브래킷 | 2.5 N·m | 2.0 N·m 미만이면 재조임 |
| 인터페이스 박스 | 8 N·m | 7 N·m 미만이면 재조임 |

:::info[주의]
브래킷을 재조임했다면 캘리브레이션 상태를 확인하고, 필요하면 [재캘리브레이션](./calibration.md#재캘리브레이션이-필요한-경우)을 수행하십시오.
:::

## 재캘리브레이션이 필요한 경우

| 상황 | 필요한 작업 |
| --- | --- |
| 상태가 `stale`로 바뀜 | 동적 캘리브레이션 |
| 브래킷을 재조임함 | 정적 + 동적 |
| 센서를 탈거·재장착함 | 정적 + 동적 |
| 앞유리·사이드미러를 교체함 | 정적 + 동적 |
| 사고 또는 강한 충격 | 정적 + 동적 |

## 모듈 교체하기

### 교체가 필요한 경우

| 증상 | 판단 |
| --- | --- |
| 청소 후에도 `degraded` 유지 | 표면 손상 가능성 |
| 상태가 `fault`이고 재부팅해도 회복 안 됨 | 하드웨어 고장 |
| 물리적 파손 | 즉시 교체 |
| 침수 흔적 | 즉시 교체 |

### 교체 절차

1. 차량 12V 배터리 음극 단자를 분리합니다.
2. 해당 모듈의 커넥터를 분리합니다.
3. 브래킷에서 모듈을 탈거합니다. 브래킷은 그대로 둡니다.
4. 새 모듈을 장착합니다. 규정 토크를 지킵니다.
5. 커넥터를 연결하고 배터리를 복원합니다.
6. [초기 진단](./power-check.md#4-초기-진단-실행하기)을 실행합니다.
7. [정적 캘리브레이션](./calibration.md#정적-캘리브레이션)과 동적 캘리브레이션을 수행합니다.

:::warning[경고]
모듈을 교체하면 이전 캘리브레이션 값은 무효입니다. 반드시 재캘리브레이션하십시오. 교체 후 캘리브레이션을 생략하면 이전 모듈의 보정값이 적용되어 오차가 커집니다.
:::

### 교체 이력 기록

교체한 모듈의 일련번호를 진단 화면의 **모듈 교체 기록**에 입력하십시오. 이후 문제 조사 시 어느 시점에 무엇을 교체했는지 추적할 수 있습니다.

## 장기 보관 시

차량을 1개월 이상 운용하지 않는다면 아래를 수행하십시오.

1. 센서 표면을 청소합니다.
2. 인터페이스 박스의 `PWR` 커넥터를 분리합니다.
3. 실내에 보관하거나 차량 커버를 씌웁니다.

보관 후 다시 운용할 때는 전체 진단과 동적 캘리브레이션을 수행하십시오.
