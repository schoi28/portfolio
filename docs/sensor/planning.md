# 설치 계획 세우기

장착을 시작하기 전에 위치와 케이블 경로를 정합니다. 이 단계를 건너뛰면 배선 도중 되돌아가야 합니다.

:::warning[경고]
차량 개조 작업입니다. 작업 전 차량의 12V 배터리 음극 단자를 분리하십시오.
:::

## 장착 위치 기준

![차량 상면도에서 본 센서 장착 위치](/img/sensor-mounting-layout.svg)

| 센서 | 위치 | 필수 조건 |
| --- | --- | --- |
| LR-40 라이다 | 루프 중앙 | 전방 180° 시야에 장애물 없음 |
| C1 전방 카메라 | 앞유리 상단 중앙 | 와이퍼 작동 범위 안 |
| C2 후방 카메라 | 트렁크 리드 상단 | 번호판 조명 간섭 없음 |
| C3 좌측 카메라 | 좌측 사이드미러 하단 | 도어 개폐 시 간섭 없음 |
| C4 우측 카메라 | 우측 사이드미러 하단 | 도어 개폐 시 간섭 없음 |
| 인터페이스 박스 | 트렁크 좌측 벽면 | 통풍 확보, 침수 위험 없음 |

### 간섭 확인 항목

장착 위치를 확정하기 전에 아래를 확인하십시오.

| 확인 | 방법 |
| --- | --- |
| 도어·트렁크 개폐 | 최대 개방 상태에서 접촉하지 않는지 |
| 와이퍼 작동 | 최고 속도에서 카메라를 건드리지 않는지 |
| 기존 센서 | 차량 자체의 레이더·카메라 시야를 가리지 않는지 |
| 안테나 | 루프 안테나와 15cm 이상 떨어져 있는지 |
| 세차 | 자동 세차기 브러시에 닿는 높이인지 |

:::warning[경고]
라이다를 루프 안테나 가까이 장착하면 통신 품질이 떨어질 수 있습니다. 15cm 이상 간격을 두십시오.
:::

## 차종별 브래킷 선택

킷에 포함된 브래킷 세트에서 차종에 맞는 것을 고릅니다.

| 브래킷 코드 | 대상 차종 | 라이다 장착 방식 |
| --- | --- | --- |
| `BR-S1` | 세단 (루프 레일 없음) | 흡착 + 볼트 고정 |
| `BR-S2` | SUV (루프 레일 있음) | 레일 클램프 |
| `BR-P1` | 픽업 (캡 루프) | 볼트 고정 |

브래킷 코드는 브래킷 뒷면에 각인되어 있습니다. 차종에 맞지 않는 브래킷을 사용하면 허용 오차 범위 안에 들어오지 않습니다.

## 케이블 경로 계획

카메라 4대와 라이다 1대의 케이블이 모두 인터페이스 박스로 모입니다.

| 구간 | 권장 경로 | 주의 |
| --- | --- | --- |
| 라이다 → 인터페이스 박스 | 루프 → C필러 내부 → 트렁크 | 루프 몰딩 분리 필요 |
| C1 → 인터페이스 박스 | 앞유리 상단 → A필러 → 도어 몰딩 → 트렁크 | 에어백 전개 경로 회피 |
| C2 → 인터페이스 박스 | 트렁크 리드 → 힌지 그로밋 → 트렁크 | 개폐 반복에 견디는 여유 길이 확보 |
| C3·C4 → 인터페이스 박스 | 미러 → 도어 → 도어 그로밋 → 트렁크 | 도어 개폐 반복 구간 |

:::danger[위험]
A필러 내부에는 커튼 에어백이 있습니다. 케이블을 에어백 전개 경로에 배치하면 전개 시 케이블이 튀어나와 위험합니다. 순정 하네스와 같은 경로로 고정하십시오.
:::

### 케이블 길이 확인

| 케이블 | 킷 제공 길이 | 여유 |
| --- | --- | --- |
| 라이다 이더넷 | 6.0 m | 세단 기준 약 1.2 m 여유 |
| 카메라 동축 (C1) | 5.0 m | 약 0.8 m 여유 |
| 카메라 동축 (C2) | 3.0 m | 약 0.5 m 여유 |
| 카메라 동축 (C3·C4) | 4.5 m | 약 0.6 m 여유 |
| 전원 | 2.5 m | 트렁크 내 배선 기준 |

여유 길이가 0.5m 미만이면 진동으로 커넥터에 힘이 걸립니다. 부족하면 연장 케이블을 별도로 준비하십시오.

## 작업 순서 정하기

권장 순서입니다. 이 순서를 따르면 되돌아가는 일이 줄어듭니다.

1. 케이블 경로를 먼저 확보합니다. 몰딩을 분리하고 통선만 해 둡니다.
2. 인터페이스 박스를 트렁크에 고정합니다.
3. 라이다를 장착하고 케이블을 연결합니다.
4. 카메라 4대를 장착하고 케이블을 연결합니다.
5. 전원을 배선합니다.
6. 몰딩을 복원하기 전에 전원을 인가해 인식을 확인합니다.
7. 확인이 끝나면 몰딩을 복원합니다.
8. 캘리브레이션을 수행합니다.

:::info[주의]
6단계를 건너뛰고 몰딩을 복원하면, 인식 실패 시 다시 분해해야 합니다. 반드시 복원 전에 확인하십시오.
:::
