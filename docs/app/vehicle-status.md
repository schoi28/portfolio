# 차량 상태 확인하기

앱을 열면 차량의 현재 상태를 한 화면에서 확인할 수 있습니다.

## 홈 화면 읽는 법

홈 화면은 세 영역으로 나뉩니다.

![홈 화면의 세 영역 구성](/img/app-home-layout.svg)

### 마지막 통신 시각

차량 요약 영역 아래에는 **차량과 마지막으로 통신한 시각**이 표시됩니다. 이 시각이 오래되었다면 화면의 숫자는 그 시점의 값이며, 지금의 상태가 아닙니다.

| 표시 | 의미 |
| --- | --- |
| 방금 전 | 5분 이내에 통신함 |
| 12분 전 | 최근 통신 시각. 값이 최신이 아닐 수 있음 |
| 연결 끊김 | 30분 이상 통신하지 못함 |

지하 주차장처럼 통신이 어려운 곳에 주차하면 연결이 끊깁니다. 차량이 지상으로 나오면 자동으로 복구됩니다.

## 배터리와 주행 가능 거리

| 항목 | 설명 |
| --- | --- |
| 배터리 잔량 | 구동 배터리의 남은 비율 |
| 주행 가능 거리 | 현재 잔량으로 갈 수 있는 추정 거리 |
| 배터리 건강도 | 출고 시 용량 대비 현재 용량. 설정에서 확인 |

주행 가능 거리는 최근 주행 패턴과 외기 온도를 반영해 계산합니다. 같은 잔량이라도 겨울에는 거리가 짧게 표시됩니다. 이는 고장이 아닙니다.

:::note
예약 공조를 사용하면 주행 가능 거리가 일시적으로 줄어듭니다. 충전 케이블이 연결된 상태라면 줄지 않습니다.
:::

## 타이어 공기압과 경고등

타이어 공기압은 네 바퀴가 각각 표시됩니다. 권장 범위를 벗어나면 해당 위치가 강조됩니다.

| 상태 | 표시 | 조치 |
| --- | --- | --- |
| 정상 | 회색 | 없음 |
| 낮음 | 주황색 | 공기압을 보충하십시오 |
| 매우 낮음 | 빨간색 | 주행 전에 점검하십시오 |

공기압은 주행 직후 온도 상승으로 높게 측정될 수 있습니다. 정확한 값은 주차 후 30분이 지난 뒤 확인하십시오.

### 차량 경고등

차량에 경고등이 켜지면 앱 알림 영역에도 같은 항목이 표시됩니다. 항목을 선택하면 의미와 권장 조치를 확인할 수 있습니다.

## 주행 리포트

최근 주행 기록을 요약해서 보여줍니다.

1. 홈 화면에서 **주행 리포트**를 선택합니다.
2. 기간을 선택합니다. 주간, 월간 중에서 고를 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 총 주행 거리 | 선택한 기간의 누적 거리 |
| 평균 전비 | 단위 전력당 주행 거리 |
| 주행 시간 | 시동이 켜져 있던 시간 |
| 급가속·급제동 횟수 | 기준값을 넘은 조작 횟수 |

주행 리포트는 하루에 한 번 갱신됩니다. 오늘의 주행은 다음 날 반영됩니다.
