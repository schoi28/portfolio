# 차량 상태 확인하기

앱에서 **배터리 잔량과 주행 가능 거리, 문 잠금 상태, 타이어 공기압, 차량 경고등, 최근 주행 기록**을 확인할 수 있습니다. 모든 값에는 차량이 마지막으로 보고한 시각이 함께 표시됩니다.

## 홈 화면 구성

앱을 열면 가장 먼저 나오는 화면입니다. 세 영역으로 나뉩니다.

![홈 화면의 세 영역 구성](/img/app-home-layout.svg)

:::note[참고]
빠른 제어의 버튼은 차량 상태에 따라 일부가 꺼진 것처럼 보일 수 있습니다. 조건을 만족하지 않아 지금은 쓸 수 없다는 뜻입니다.
:::

| 영역 | 위치 | 보이는 것 | 선택하면 |
| --- | --- | --- | --- |
| 차량 요약 | 위쪽 | 배터리 잔량, 주행 가능 거리, 문 잠금 상태, 마지막 통신 시각 | 차량 상태 상세 화면이 열립니다 |
| 빠른 제어 | 가운데 | 잠금, 실내 온도, 충전, 차량 찾기 | 해당 기능이 실행됩니다 ([원격으로 제어하기](./remote-control.md)) |
| 알림 | 아래쪽 | 소프트웨어 업데이트, 정비 시기, 센서 청소, 차량 경고등 | 해당 항목의 설명과 조치가 열립니다 |

**차량 요약**을 선택하면 열리는 상세 화면에 배터리, 타이어, 주행 리포트가 탭으로 들어 있습니다. 아래 각 절의 첫 줄에 들어가는 경로를 적었습니다.

## 값이 언제 갱신되었는지 확인하기

차량 요약 영역 아래에 **차량과 마지막으로 통신한 시각**이 표시됩니다. 화면의 값은 모두 이 시점에 차량이 보고한 값입니다.

> **어디서 보나** 홈 화면 > 차량 요약 영역 아래

| 표시 | 의미 |
| --- | --- |
| 방금 전 | 5분 이내에 통신함 |
| 12분 전 | 그 시점의 값. 이후 차량 상태가 바뀌었을 수 있음 |
| 연결 끊김 | 30분 이상 통신하지 못함 |

주행을 마치고 지상에 주차한 상태라면 보통 **5분 이내**로 표시됩니다. 지하 주차장이나 전파가 약한 곳에 주차했다면 시간이 길어지는 것이 정상이며, 차량이 지상으로 나오면 자동으로 복구됩니다.

:::info[주의]
통신이 잘 되는 곳에 주차했는데도 **30분 이상** 바뀌지 않거나 '연결 끊김'이 계속된다면 점검이 필요합니다. [문제 해결](./troubleshooting.md#차량이-연결되지-않아요)을 참고하십시오.
:::

## 배터리와 주행 가능 거리

> **어디서 보나** 홈 화면 차량 요약 영역. 자세한 값은 **차량 요약 > 배터리** 탭

| 항목 | 설명 | 위치 |
| --- | --- | --- |
| 배터리 잔량 | 주행용 배터리의 남은 비율 | 홈 화면 차량 요약 |
| 주행 가능 거리 | 현재 잔량으로 갈 수 있는 추정 거리 | 홈 화면 차량 요약 |
| 충전 상태 | 충전 중인지, 완료까지 남은 시간 | 차량 요약 > 배터리 |
| 배터리 건강도 | 출고 시 용량 대비 현재 용량 | 설정 > 차량 정보 |

주행 가능 거리는 최근 주행 패턴과 외기 온도를 반영해 계산합니다. 같은 잔량이라도 겨울에는 거리가 짧게 표시됩니다. 이는 고장이 아닙니다.

:::note[참고]
실내 온도 예약을 사용하면 주행 가능 거리가 일시적으로 줄어듭니다. 충전 케이블이 연결된 상태라면 줄지 않습니다.
:::

## 타이어 공기압

> **어디서 보나** 차량 요약 > 타이어 탭

네 바퀴의 공기압이 각각 표시됩니다. 적정 범위를 벗어나면 해당 위치가 강조됩니다.

| 상태 | 표시 | 조치 |
| --- | --- | --- |
| 정상 | 회색 | 없음 |
| 낮음 | 주황색 | 공기압을 채우십시오 |
| 매우 낮음 | 빨간색 | 주행 전에 점검하십시오 |

공기압은 주행 직후 온도 상승으로 높게 측정될 수 있습니다. 정확한 값은 주차 후 30분이 지난 뒤 확인하십시오.

## 차량 경고등

> **어디서 보나** 홈 화면 알림 영역

차량 계기판에 경고등이 켜지면 앱 알림 영역에도 같은 항목이 표시됩니다. 항목을 선택하면 경고등의 의미와 해야 할 일을 확인할 수 있습니다.

운행에 지장이 있는 경고등은 알림 영역 맨 위에 표시되고, 선택하면 가까운 서비스 센터 안내로 이어집니다.

## 주행 리포트

> **어디서 보나** 차량 요약 > 주행 리포트 탭

최근 주행 기록을 요약해서 보여줍니다.

1. 홈 화면에서 **차량 요약**을 선택합니다.
2. **주행 리포트** 탭을 선택합니다.
3. 기간을 선택합니다. 주간, 월간 중에서 고를 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| 총 주행 거리 | 선택한 기간의 누적 거리 |
| 평균 전비 | 단위 전력당 주행 거리 |
| 주행 시간 | 시동이 켜져 있던 시간 |
| 급가속·급제동 횟수 | 기준보다 센 조작 횟수 |

주행 리포트는 하루에 한 번, **매일 오전 6시**에 새로 계산됩니다. 오늘 주행한 내용은 다음 날 오전 6시 이후에 나타납니다.
