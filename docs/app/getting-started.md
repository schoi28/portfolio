# 시작하기

앱을 설치하고 차량을 연결하기까지 약 10분이 걸립니다.

## 시작하기 전에

다음을 준비합니다.

- 차량 등록증 또는 차대번호(VIN) 17자리
- 차량 실내에 있는 등록용 QR 코드. 운전석 문을 열면 안쪽 기둥에 붙어 있습니다.
- 차량이 통신이 되는 곳에 있어야 합니다. 지하 주차장에서는 연결이 실패할 수 있습니다.

## 1. 앱 설치하기

1. App Store 또는 Google Play에서 `VELA Drive`를 검색합니다.
2. 앱을 설치하고 실행합니다.
3. 알림 권한을 허용합니다. 허용하지 않으면 업데이트와 정비 알림을 받을 수 없습니다.

## 2. 계정 만들기

1. 첫 화면에서 **계정 만들기**를 선택합니다.
2. 이메일 주소와 비밀번호를 입력합니다.
3. 받은 인증 메일에서 링크를 선택합니다.
4. 인증이 끝나면 앱으로 돌아와 로그인합니다.

## 3. 차량 연결하기

:::caution
차량 연결은 계정당 한 번만 수행합니다. 이미 다른 계정에 연결된 차량은 이전 계정에서 연결을 해제해야 합니다.
:::

1. **차량 연결**을 선택합니다.
2. 차량 실내의 QR 코드를 촬영합니다. 코드를 찾을 수 없으면 **직접 입력**을 선택해 차대번호 17자리를 입력합니다.
3. 차량 화면에 6자리 확인 코드가 표시됩니다.
4. 앱에 그 코드를 입력합니다.
5. 홈 화면에 차량 이름과 배터리 잔량이 표시되면 연결이 완료된 것입니다.

연결에는 최대 2분이 걸립니다. 이 시간 동안 차량의 시동을 끄지 마십시오.

## 4. 첫 화면 둘러보기

홈 화면은 세 영역으로 나뉩니다.

| 영역 | 위치 | 내용 |
| --- | --- | --- |
| 차량 요약 | 위쪽 | 배터리 잔량, 주행 가능 거리, 문 잠금 상태 |
| 빠른 제어 | 가운데 | 잠금, 공조, 충전, 차량 찾기 |
| 알림 | 아래쪽 | 소프트웨어 업데이트, 정비 시기, 센서 청소 |

차량 요약은 마지막으로 차량과 통신한 시각을 함께 표시합니다. 표시 시각이 오래되었다면 차량이 통신하지 못하는 상태입니다.

## 연결이 실패했을 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 확인 코드가 차량 화면에 나오지 않음 | 차량이 통신되지 않는 곳에 있음 | 지상으로 이동한 뒤 다시 시도합니다 |
| "이미 등록된 차량입니다" | 다른 계정에 연결되어 있음 | 이전 계정에서 연결을 해제합니다 |
| 코드 입력 후 응답 없음 | 확인 코드 유효 시간 5분 초과 | 2단계부터 다시 시작합니다 |
| QR 코드가 인식되지 않음 | 코드 손상 또는 조명 부족 | 차대번호를 직접 입력합니다 |
