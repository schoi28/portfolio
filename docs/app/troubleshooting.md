# 문제 해결하기

증상별로 확인할 항목을 정리했습니다. 위에서부터 순서대로 확인하십시오.

## 차량이 연결되지 않아요

가장 흔한 원인은 차량이 통신되지 않는 곳에 있는 경우입니다.

| 확인 | 방법 | 해결되지 않으면 |
| --- | --- | --- |
| 주차 위치 | 지하 주차장이라면 지상으로 이동 후 확인합니다 | 다음 항목으로 |
| 마지막 통신 시각 | 홈 화면에서 확인합니다. 30분 이상이면 차량 쪽 문제입니다 | 다음 항목으로 |
| 보조 배터리 | 시동을 걸어 10분 이상 충전합니다 | 다음 항목으로 |
| 앱 재시작 | 앱을 완전히 종료 후 다시 실행합니다 | 다음 항목으로 |
| 차량 재연결 | **설정 > 차량 > 연결 해제** 후 다시 연결합니다 | 서비스 센터 문의 |

:::note[참고]
차량을 2주 이상 주행하지 않으면 배터리 보호를 위해 통신 주기가 길어집니다. 이 경우 앱 응답이 최대 30분 지연될 수 있으며, 고장이 아닙니다.
:::

## 원격 명령이 실행되지 않아요

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| "차량과 연결할 수 없습니다" | 통신 불가 위치 | 위 항목을 먼저 확인합니다 |
| "차량이 응답하지 않습니다" | 보조 배터리 부족 | 시동을 걸어 충전합니다 |
| "이전 명령을 처리 중입니다" | 명령이 겹침 | 30초 후 다시 시도합니다 |
| "차량 상태를 확인하세요" | 사전 조건 미충족 | 아래 표를 확인합니다 |
| 응답 없이 대기만 함 | 소프트웨어 설치 중 | 설치가 끝날 때까지 기다립니다 |

### 명령별 사전 조건

| 명령 | 필요한 상태 |
| --- | --- |
| 실내 온도 | 주차 상태 |
| 충전 시작 | 충전 케이블 연결됨 |
| 시동 (디지털 키) | 차량 근처, 디지털 키 등록됨 |
| 모든 명령 | 보조 배터리 20% 이상 |

## 업데이트가 실패했어요

설치에 실패하면 차량이 자동으로 이전 버전으로 되돌아갑니다. 차량은 정상적으로 사용할 수 있습니다.

| 알림 문구 | 원인 | 조치 |
| --- | --- | --- |
| 배터리가 부족합니다 | 잔량 30% 미만 | 충전 후 다시 시도합니다 |
| 차량 상태를 확인하세요 | 주차 상태가 아니었음 | 기어를 P로 두고 다시 시도합니다 |
| 설치가 중단되었습니다 | 설치 중 시동을 걸었음 | 다시 시도합니다 |
| 설치에 실패했습니다 | 원인 미상 | 3회 반복되면 서비스 센터에 문의하십시오 |

같은 업데이트가 3회 연속 실패하면 자동 재시도가 중단되고, 앱에 서비스 센터 안내가 표시됩니다.

## 알림이 오지 않아요

1. 휴대폰 설정에서 VELA Drive의 알림 권한이 켜져 있는지 확인합니다.
2. 앱의 **설정 > 알림**에서 해당 항목이 켜져 있는지 확인합니다.
3. 휴대폰의 절전 모드나 방해 금지 모드가 켜져 있는지 확인합니다.
4. 앱을 다시 로그인합니다.

Android 기기에서 앱이 백그라운드에서 종료되면 알림이 지연될 수 있습니다. 배터리 최적화 대상에서 VELA Drive를 제외하십시오.

## 디지털 키가 인식되지 않아요

| 확인 | 방법 |
| --- | --- |
| 블루투스 | 휴대폰의 블루투스가 켜져 있는지 확인합니다 |
| 위치 권한 | 앱의 위치 권한이 "항상 허용"인지 확인합니다 |
| 배터리 | 휴대폰 배터리가 5% 미만이면 동작하지 않을 수 있습니다 |
| 키 상태 | **디지털 키** 화면에서 키가 활성 상태인지 확인합니다 |
| 재등록 | 키를 해제하고 차량 안에서 다시 등록합니다 |

물리 스마트키는 디지털 키와 무관하게 항상 사용할 수 있습니다.

## 주행 가능 거리가 실제와 달라요

주행 가능 거리는 추정값입니다. 아래 요인으로 달라집니다.

- 외기 온도가 낮으면 배터리 효율이 떨어집니다.
- 고속 주행이 많으면 전비가 나빠집니다.
- 에어컨이나 히터를 강하게 쓰면 소비가 늘어납니다.

최근 주행 패턴을 반영해 계속 보정되므로, 주행 습관이 바뀌면 며칠에 걸쳐 값이 조정됩니다.

## 앱이 느리거나 멈춰요

1. 앱을 완전히 종료 후 다시 실행합니다.
2. 앱을 최신 버전으로 갱신합니다.
3. 휴대폰을 재시작합니다.
4. 앱을 삭제하고 다시 설치합니다. 재설치해도 차량 연결과 디지털 키는 유지됩니다.

## 그래도 해결되지 않으면

**설정 > 문의하기**에서 진단 정보를 첨부해 문의할 수 있습니다. 진단 정보에는 앱 버전, 차량 소프트웨어 버전, 최근 오류 기록이 포함되며, 위치 정보나 주행 기록은 포함되지 않습니다.
