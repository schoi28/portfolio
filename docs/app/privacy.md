# 데이터와 개인정보 관리하기

차량이 어떤 데이터를 수집하고, 어디에 쓰이며, 어떻게 관리할 수 있는지 설명합니다.

## 수집되는 데이터

| 종류 | 예시 | 수집 시점 | 보관 기간 |
| --- | --- | --- | --- |
| 차량 상태 | 배터리 잔량, 타이어 공기압, 도어 상태 | 상시 | 90일 |
| 주행 기록 | 주행 거리, 시간, 전비 | 주행 중 | 12개월 |
| 위치 | 주행 경로, 마지막 주차 위치 | 주행 중 | 30일 |
| 진단 정보 | 오류 코드, 부품 상태 | 이상 발생 시 | 24개월 |
| 앱 사용 기록 | 원격 명령 실행 이력 | 명령 실행 시 | 90일 |

보관 기간이 지난 데이터는 자동으로 삭제됩니다.

## 데이터가 쓰이는 곳

| 목적 | 사용하는 데이터 |
| --- | --- |
| 앱 기능 제공 | 차량 상태, 위치 |
| 정비 시기 안내 | 주행 기록, 진단 정보 |
| 소프트웨어 개선 | 진단 정보 (식별 정보를 제거한 형태) |
| 고장 분석 | 진단 정보 |

주행 경로와 위치 정보는 광고나 제3자 제공에 사용되지 않습니다.

## 데이터 관리하기

### 수집 항목 조정하기

**설정 > 개인정보 > 데이터 수집**에서 항목별로 조정할 수 있습니다.

| 항목 | 끌 수 있는지 | 끄면 제한되는 기능 |
| --- | --- | --- |
| 위치 | 예 | 차량 찾기, 주행 경로 |
| 주행 기록 | 예 | 주행 리포트 |
| 진단 정보 | 아니오 | — (안전 관련 필수 항목) |
| 소프트웨어 개선 참여 | 예 | 없음 |

:::note[참고]
진단 정보는 안전과 직결되므로 수집을 중단할 수 없습니다. 다만 차량 식별 정보와 분리되어 처리됩니다.
:::

### 데이터 내려받기

**설정 > 개인정보 > 내 데이터 내려받기**에서 수집된 데이터를 파일로 받을 수 있습니다. 요청 후 최대 7일이 걸리며, 준비되면 알림이 옵니다.

### 데이터 삭제하기

**설정 > 개인정보 > 데이터 삭제**에서 삭제할 항목을 선택합니다.

:::warning[경고]
삭제한 데이터는 복구할 수 없습니다. 주행 리포트와 사용 이력도 함께 사라집니다.
:::

법령에 따라 보관 의무가 있는 진단 정보는 삭제 요청 후에도 일정 기간 보관될 수 있습니다.

## 차량을 다른 사람에게 넘길 때

차량을 판매하거나 반납하기 전에 반드시 아래를 수행하십시오.

1. **설정 > 디지털 키**에서 공유한 키를 모두 회수합니다.
2. **설정 > 개인정보 > 데이터 삭제**에서 주행 기록과 위치를 삭제합니다.
3. **설정 > 차량 > 연결 해제**를 선택합니다.
4. 차량 화면에서도 초기화를 수행합니다. 차량에 저장된 즐겨찾기, 연동된 휴대폰 정보가 지워집니다.

연결을 해제하면 앱에서는 데이터가 즉시 사라지지만, 차량 자체에 남은 정보는 4단계를 거쳐야 지워집니다.

## 공유된 사용자의 데이터

디지털 키를 공유받은 사람의 데이터는 다음과 같이 처리됩니다.

| 항목 | 소유자가 볼 수 있는지 |
| --- | --- |
| 잠금 해제·시동 시각 | 예 |
| 사용자 이름 | 예 |
| 주행 경로 | 아니요 |
| 주행 리포트 | 아니요 |

## 문의

개인정보 처리에 관한 문의는 **설정 > 개인정보 > 문의하기**를 이용하십시오.
