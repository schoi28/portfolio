# 디지털 키

휴대폰으로 차량을 열고 시동을 걸 수 있습니다. 가족이나 지인에게 키를 공유할 수도 있습니다.

## 디지털 키 등록하기

차량 안에서 진행해야 합니다.

1. 차량에 탑승해 시동을 겁니다.
2. 앱에서 **디지털 키 > 키 등록**을 선택합니다.
3. 휴대폰을 차량의 무선 충전 패드 위에 올립니다.
4. 차량 화면에 표시되는 6자리 코드를 앱에 입력합니다.
5. 등록이 완료되면 앱에 키 아이콘이 표시됩니다.

등록에는 약 1분이 걸립니다. 이 시간 동안 휴대폰을 패드에서 치우지 마십시오.

### 사용 방법

| 동작 | 방법 |
| --- | --- |
| 도어 잠금 해제 | 휴대폰을 들고 운전석 손잡이를 잡습니다 |
| 시동 | 탑승 후 시동 버튼을 누릅니다 |
| 도어 잠금 | 하차 후 손잡이의 잠금 버튼을 누릅니다 |

디지털 키는 휴대폰 전원이 꺼져도 최대 6시간 동안 동작합니다. 물리 스마트키는 계속 사용할 수 있습니다.

## 가족과 키 공유하기

![키 공유가 진행되는 네 단계](/img/app-key-sharing.svg)

1. **디지털 키 > 키 공유**를 선택합니다.
2. 받는 사람의 이메일 주소를 입력합니다.
3. 권한을 선택합니다.
4. **초대 보내기**를 선택합니다.

받는 사람은 초대 메일의 링크를 선택해 앱을 설치하고, 자신의 계정으로 수락합니다. 수락하면 즉시 사용할 수 있습니다.

:::note
초대는 발송 후 **72시간**이 지나면 만료됩니다. 만료되면 다시 보내야 합니다.
:::

### 권한 종류

| 권한 | 할 수 있는 것 | 할 수 없는 것 |
| --- | --- | --- |
| 전체 | 잠금·해제, 시동, 원격 제어, 주행 | 키 공유, 소유자 변경 |
| 운전 | 잠금·해제, 시동, 주행 | 원격 제어, 키 공유 |
| 출입 | 잠금·해제만 | 시동, 주행 |

**출입** 권한은 택배 수령이나 세차처럼 차 안에 접근만 필요한 경우에 사용합니다.

### 사용 기간 제한하기

권한을 선택할 때 사용 기간을 함께 지정할 수 있습니다.

1. 권한 선택 화면에서 **기간 제한**을 켭니다.
2. 시작일과 종료일을 지정합니다.

종료일이 지나면 키가 자동으로 비활성화됩니다. 별도로 회수하지 않아도 됩니다.

## 공유 권한 관리하고 회수하기

1. **디지털 키 > 공유 중인 키**를 선택합니다.
2. 목록에서 대상을 선택합니다.
3. 권한을 변경하거나 **키 회수**를 선택합니다.

:::warning
키를 회수하면 상대방은 즉시 차량을 사용할 수 없습니다. 상대가 차량 안에 있거나 주행 중이어도 다음 시동부터 적용됩니다. 되돌리려면 처음부터 다시 공유해야 합니다.
:::

### 공유 이력 확인하기

**디지털 키 > 사용 이력**에서 누가 언제 차량을 사용했는지 확인할 수 있습니다. 이력은 90일간 보관됩니다.

| 기록되는 항목 | 예시 |
| --- | --- |
| 잠금 해제 | 3월 4일 18:22, 홍길동 |
| 시동 | 3월 4일 18:24, 홍길동 |

## 휴대폰을 바꾸거나 잃어버렸을 때

| 상황 | 조치 |
| --- | --- |
| 휴대폰 교체 | 새 휴대폰에서 앱 설치 후 다시 등록합니다. 이전 키는 자동으로 해제됩니다 |
| 휴대폰 분실 | 다른 기기에서 로그인해 **디지털 키 > 이 기기 키 해제**를 선택합니다 |
| 계정 비밀번호 유출 의심 | 비밀번호를 변경하면 모든 디지털 키가 해제됩니다. 다시 등록해야 합니다 |
