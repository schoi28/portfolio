# VELA Drive 앱 사용 설명서

VELA Drive는 차량 상태를 확인하고 원격으로 제어하는 모바일 앱입니다. 이 문서는 VELA Drive를 처음 쓰는 차량 소유자를 대상으로 합니다.

:::note
이 문서는 포트폴리오용으로 창작한 가상 제품의 문서입니다. 실재하는 제품이나 조직과 관련이 없습니다.
:::

| 하고 싶은 것 | 참고할 곳 |
| --- | --- |
| 앱을 설치하고 차량을 연결한다 | [시작하기](./getting-started.md) |
| 배터리와 주행 가능 거리를 확인한다 | 차량 상태 확인하기 (작성 예정) |
| 타기 전에 실내 온도를 맞춘다 | [원격으로 제어하기](./remote-control.md) |
| 가족과 디지털 키를 공유한다 | 디지털 키 (작성 예정) |
| 소프트웨어 업데이트를 설치한다 | 소프트웨어 업데이트 (작성 예정) |
| 연결이 안 될 때 확인한다 | 문제 해결 (작성 예정) |

## 준비물

- VELA 플랫폼이 적용된 차량
- iOS 16 이상 또는 Android 12 이상
- 차량에 등록할 수 있는 이메일 주소

## 설계 노트

> 이 문서를 왜 이렇게 설계했는지에 대한 기록입니다. 실제 제품 문서에는 포함되지 않습니다.

**독자**: 차량 소유자. 자동차 정비 지식도, 소프트웨어 지식도 없다고 가정했습니다. 휴대폰 화면으로, 차 앞에 서서, 대체로 급한 상황에 읽습니다.

**구조 결정**: 개요 페이지를 "무엇을 할 수 있는가"가 아니라 **"무엇을 하고 싶은가"** 표로 시작했습니다. 기능 목록으로 시작하면 독자가 자기 문제를 기능 이름으로 번역해야 합니다. 목적을 먼저 제시하면 그 번역을 문서가 대신합니다.

**용어 처리**: 이 문서에서는 'OTA'를 쓰지 않고 '소프트웨어 업데이트'로 씁니다. 같은 개념을 [VELA Deploy 운영 가이드](../deploy/intro.md)에서는 '무선 업데이트(OTA)'로, [API 문서](../api/intro.md)에서는 `campaign`으로 부릅니다. 용어집에는 세 표기가 모두 등재되어 있고, 어느 문서에서 어느 표기를 쓰는지도 함께 관리합니다.

**다른 세트와 다르게 처리한 점**: 사용자 문서에는 안전 경고 등급 중 '위험'을 쓰지 않습니다. 사용자는 하드웨어를 직접 만지지 않기 때문입니다. 대신 되돌릴 수 없는 동작(키 공유 회수, 업데이트 중 시동 끄기)에만 '경고'를 사용합니다.

**의도적으로 넣지 않은 것**: 화면 스크린샷을 전제하지 않고 작성했습니다. 앱 UI는 자주 바뀌고, 스크린샷이 낡으면 문서 전체의 신뢰가 떨어집니다. 화면 요소는 이름으로 지칭하고, 위치는 필요할 때만 설명합니다.
