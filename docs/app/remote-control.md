# 원격으로 제어하기

앱에서 **문 잠금과 해제, 실내 온도 맞추기, 충전 시작과 예약, 주차한 차 찾기**를 할 수 있습니다. 차량 옆에 있지 않아도 되지만, 차량이 통신되는 곳에 있어야 합니다.

## 모든 원격 명령의 공통 조건

원격 명령은 차량 상태에 따라 실패합니다. 아래 조건을 만족해야 실행됩니다.

| 조건 | 이유 |
| --- | --- |
| 차량이 통신되는 곳에 있음 | 명령이 차량에 전달되어야 합니다 |
| 12V 보조 배터리 잔량 20% 이상 | 잔량이 낮으면 차량이 통신을 중단합니다 |
| 최근 명령이 완료됨 | 명령은 한 번에 하나씩 처리됩니다 |

명령을 보내면 앱에 "전송 중"이 표시되고, 차량이 실행을 마치면 "완료"로 바뀝니다. 30초 안에 완료되지 않으면 실패로 처리됩니다.

## 도어 잠그고 열기

:::info[주의]
차량 안에 사람이 있는 상태에서 원격으로 잠그면 안에서 문을 열 때 경보가 울릴 수 있습니다.
:::

1. 홈 화면에서 **잠금** 또는 **잠금 해제**를 선택합니다.
2. 잠금 상태가 바뀌면 차량의 비상등이 한 번 깜박입니다.

원격으로 잠금을 해제하면 30초 뒤 자동으로 다시 잠깁니다. 그 사이에 문을 열지 않으면 잠금 상태로 돌아갑니다.

## 타기 전에 실내 온도 맞추기

주행 전에 실내 온도를 원하는 온도로 맞춰 두는 기능입니다. 전기차에서는 주행 가능 거리가 줄어들 수 있습니다.

1. 홈 화면에서 **실내 온도**를 선택합니다.
2. 목표 온도를 설정합니다. 설정 범위는 17~28°C입니다.
3. **지금 시작**을 선택합니다.

실내 온도 조절은 최대 30분 동안 작동한 뒤 자동으로 꺼집니다.

### 출발 시각에 맞춰 예약하기

1. **실내 온도** 화면에서 **예약**을 선택합니다.
2. 출발 시각과 반복할 요일을 설정합니다.
3. **저장**을 선택합니다.

차량은 설정한 출발 시각에 목표 온도가 되도록 미리 작동을 시작합니다. 시작 시각은 외기 온도에 따라 자동으로 결정됩니다.

:::note[참고]
충전 케이블이 연결된 상태에서 실내 온도 예약을 사용하면 주행 가능 거리가 줄지 않습니다.
:::

## 충전 시작하고 중지하기

충전 케이블이 연결되어 있어야 합니다.

1. 홈 화면에서 **충전**을 선택합니다.
2. **충전 시작** 또는 **충전 중지**를 선택합니다.

### 충전 예약하기

전기 요금이 싼 시간대에 충전하려면 예약을 사용합니다.

1. **충전** 화면에서 **예약**을 선택합니다.
2. 충전을 시작할 시각과 목표 충전량을 설정합니다.
3. **저장**을 선택합니다.

예약을 설정해도 케이블을 연결한 직후 **지금 충전**을 선택하면 즉시 충전이 시작됩니다.

## 주차한 차 찾기

1. 홈 화면에서 **차량 찾기**를 선택합니다.
2. 지도에 마지막 주차 위치가 표시됩니다.
3. 가까이 있다면 **경적·비상등**을 선택합니다. 비상등이 3회 깜박이고 경적이 한 번 울립니다.

주차 위치는 시동을 끈 시점을 기준으로 기록됩니다. 시동을 끈 뒤 차량이 견인되었다면 위치가 바뀌지 않습니다.

## 명령이 실행되지 않을 때

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| "차량과 연결할 수 없습니다" | 통신이 되지 않는 곳에 주차됨 | 차량이 지상으로 나온 뒤 다시 시도합니다 |
| "차량이 응답하지 않습니다" | 보조 배터리 잔량 부족 | 차량 시동을 걸어 충전한 뒤 다시 시도합니다 |
| "이전 명령을 처리 중입니다" | 명령이 겹침 | 30초 기다린 뒤 다시 시도합니다 |
| 실내 온도 조절이 30분 만에 꺼짐 | 정상 동작입니다 | 필요하면 다시 시작합니다 |
| 실내 온도 예약이 작동하지 않음 | 소프트웨어 업데이트 설치 중 | 업데이트가 끝난 뒤 다시 작동합니다 |
