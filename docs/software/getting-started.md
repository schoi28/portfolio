# 시작하기

계정을 만들고 첫 설치 지점을 등록하기까지의 절차입니다.

## 1. 계정 만들기

1. [console.aeris.example.com](https://console.aeris.example.com)에 접속합니다.
2. **계정 만들기**를 선택합니다.
3. 업무용 이메일 주소를 입력합니다. 개인 메일 주소로는 팀 초대 기능을 사용할 수 없습니다.
4. 받은 인증 메일에서 링크를 선택해 인증을 완료합니다.

## 2. 설치 지점 만들기

센서를 등록하려면 설치 지점이 먼저 있어야 합니다.

1. 왼쪽 메뉴에서 **설치 지점**을 선택합니다.
2. **새 설치 지점**을 선택합니다.
3. 이름과 주소를 입력합니다. 이름은 나중에 알림 메시지에 그대로 표시되므로 "3층 회의실"처럼 현장에서 통용되는 이름을 권장합니다.

## 3. 센서 등록하기

물리적 설치가 끝난 상태여야 합니다. 아직이라면 [센서 설치하기](../hardware/setup.md)를 먼저 진행하십시오.

1. 설치 지점을 선택합니다.
2. **센서 추가**를 선택합니다.
3. 센서 뒷면의 등록 코드 8자리를 입력합니다.

## 4. 대시보드 확인하기

등록 후 약 3분이 지나면 대시보드에 첫 측정값이 나타납니다.

| 지표 | 단위 | 권장 범위 |
| --- | --- | --- |
| 이산화탄소 | ppm | 1,000 이하 |
| 미세먼지 (PM2.5) | µg/m³ | 15 이하 |
| 온도 | °C | 18~24 |
| 습도 | % | 40~60 |

측정값이 권장 범위를 벗어날 때 알림을 받으려면 알림 규칙을 만들어야 합니다.
