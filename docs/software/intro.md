# Aeris Console 가이드

Aeris Console은 설치된 센서를 관리하고 측정 데이터를 확인하는 웹 애플리케이션입니다. 이 문서는 여러 설치 지점을 운영하는 시설 관리자를 대상으로 합니다.

## 이 문서에서 다루는 것

- [시작하기](./getting-started.md) — 계정 생성부터 첫 대시보드 확인까지
- 알림 규칙 만들기 (작성 예정)
- 권한과 팀 관리 (작성 예정)

## 주요 개념

| 개념 | 설명 |
| --- | --- |
| 설치 지점 | 센서가 물리적으로 놓인 공간. 층·호실 단위로 나눕니다. |
| 센서 | 등록된 Aeris Sense 기기 한 대. |
| 알림 규칙 | 측정값이 기준을 벗어났을 때 알림을 보내는 조건. |

## 설계 노트

> 이 문서를 왜 이렇게 설계했는지에 대한 기록입니다.

**독자**: 시설 관리자. 기술 배경은 없지만 업무 도구를 매일 사용하는 사람으로 가정했습니다. 하드웨어 문서의 독자보다 반복 사용 빈도가 높습니다.

**구조 결정**: 하드웨어 문서가 순서대로 읽는 튜토리얼이라면, 이 문서는 필요한 작업만 찾아 읽는 하우투 가이드입니다. 그래서 페이지 제목을 모두 "~하기" 형태의 작업 단위로 통일하고, 페이지 하나가 작업 하나에 대응하도록 나눴습니다.

**용어 처리**: 개념 세 가지를 문서 앞에 정의한 이유는, 이 용어들이 API 문서에서 각각 `site`, `sensor`, `alert_rule`이라는 이름으로 다시 등장하기 때문입니다. 독자가 개발자 문서로 넘어갔을 때 같은 개념임을 알아볼 수 있도록 대응 관계를 미리 만들어 뒀습니다.
