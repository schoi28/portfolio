# Aeris API v1

Aeris API로 센서를 등록하고 측정 데이터를 조회할 수 있습니다. 이 문서는 Aeris를 자사 시스템에 연동하려는 개발자를 대상으로 합니다.

```
https://api.aeris.example.com/v1
```

## 이 문서에서 다루는 것

- [인증](./authentication.md) — API 키 발급과 요청 서명
- 엔드포인트 레퍼런스 (작성 예정)
- 에러 코드 (작성 예정)
- 웹훅 (작성 예정)

## 리소스 모델

콘솔의 개념과 API 리소스는 다음과 같이 대응합니다.

| 콘솔 용어 | API 리소스 | 설명 |
| --- | --- | --- |
| 설치 지점 | `site` | 센서를 담는 상위 단위 |
| 센서 | `sensor` | 등록된 기기 한 대 |
| 알림 규칙 | `alert_rule` | 임계값 조건 |
| 측정값 | `reading` | 5분 간격 시계열 데이터 |

## 요청 예시

```bash
curl https://api.aeris.example.com/v1/sites \
  -H "Authorization: Bearer $AERIS_API_KEY"
```

## 설계 노트

> 이 문서를 왜 이렇게 설계했는지에 대한 기록입니다.

**독자**: 연동을 담당하는 백엔드 개발자. Aeris 제품 자체는 처음 접한다고 가정했습니다.

**구조 결정**: 개발자 문서에서 가장 먼저 필요한 것은 "이 제품의 데이터 모델이 어떻게 생겼는가"입니다. 그래서 엔드포인트 목록보다 리소스 모델 표를 앞에 뒀습니다.

**콘솔 문서와의 연결**: 리소스 모델 표에 콘솔 용어를 함께 적은 이유는, 개발자가 고객사 담당자와 대화할 때 용어가 어긋나는 문제를 줄이기 위해서입니다. 같은 개념에 두 개의 이름이 존재한다는 사실을 숨기지 않고 대응표로 드러내는 편이 낫다고 판단했습니다.

**문서 유형**: 레퍼런스로 분류했습니다. 순서대로 읽는 문서가 아니라 필요한 항목을 검색해 찾는 문서이므로, 각 항목이 독립적으로 이해되도록 작성합니다.
