# Aeris Sense S1 사용 설명서

Aeris Sense S1은 실내 공기질을 측정해 Aeris Console로 전송하는 센서입니다. 이 문서는 제품을 처음 설치하는 사용자를 대상으로 합니다.

:::warning 안전 경고
센서를 물이 닿는 곳이나 직사광선이 드는 곳에 설치하지 마십시오. 내부 습도 센서가 손상되어 측정값이 부정확해집니다.
:::

## 이 문서에서 다루는 것

- [설치하기](./setup.md) — 개봉부터 첫 측정값 확인까지
- 트러블슈팅 (작성 예정)
- 사양 (작성 예정)

## 구성품

| 항목 | 수량 |
| --- | --- |
| Aeris Sense S1 본체 | 1 |
| 벽면 거치대 | 1 |
| USB-C 전원 케이블 (2m) | 1 |
| 나사 세트 | 1 |

## 설계 노트

> 이 문서를 왜 이렇게 설계했는지에 대한 기록입니다. 실제 제품 문서에는 포함되지 않습니다.

**독자**: 기술 배경이 없는 최종 사용자. 설치 현장에서 휴대폰으로 읽을 가능성이 높다고 가정했습니다.

**구조 결정**: 하드웨어 문서에서는 안전 경고를 맨 앞에 배치했습니다. 사용자가 문서를 처음부터 읽지 않고 필요한 절차만 찾아 읽는다는 전제 아래, 손상을 유발할 수 있는 정보는 어느 페이지에 진입하든 먼저 보이도록 각 문서 상단에 반복 노출합니다.

**소프트웨어 문서와 다르게 처리한 점**: 하드웨어는 되돌리기 어려운 작업(벽 타공, 전원 연결)이 포함되므로 절차마다 "진행 전 확인" 항목을 넣었습니다. 소프트웨어 문서에는 이 장치가 없습니다.
