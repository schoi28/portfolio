# 설치하기

개봉부터 첫 측정값을 확인하기까지 약 15분이 걸립니다.

:::warning 안전 경고
전원을 연결한 상태에서 거치대를 분리하지 마십시오.
:::

## 시작하기 전에

- 설치 지점에서 2.4GHz Wi-Fi 신호가 잡히는지 확인합니다. 센서는 5GHz를 지원하지 않습니다.
- 콘센트에서 2m 이내인지 확인합니다. 제공되는 케이블 길이입니다.
- Aeris Console 계정이 필요합니다. 없다면 [계정 만들기](../software/getting-started.md)를 먼저 진행하십시오.

## 1. 거치대 부착하기

1. 바닥에서 1.2~1.5m 높이의 벽면을 고릅니다. 호흡 높이에 가까울수록 측정값이 실제 체감에 가깝습니다.
2. 거치대를 벽에 대고 나사 구멍 두 곳을 표시합니다.
3. 표시한 위치에 나사를 조여 거치대를 고정합니다.

## 2. 전원 연결하기

1. USB-C 케이블을 센서 하단 단자에 연결합니다.
2. 어댑터를 콘센트에 꽂습니다.
3. 전면 표시등이 **흰색으로 깜박이면** 준비 상태입니다.

| 표시등 | 상태 |
| --- | --- |
| 흰색 깜박임 | Wi-Fi 연결 대기 |
| 흰색 켜짐 | 정상 측정 중 |
| 주황색 깜박임 | Wi-Fi 연결 실패 |
| 꺼짐 | 전원 없음 |

## 3. 콘솔에 등록하기

1. Aeris Console에 로그인합니다.
2. **설치 지점 > 센서 추가**를 선택합니다.
3. 센서 뒷면의 등록 코드 8자리를 입력합니다.
4. 표시등이 흰색으로 켜지면 등록이 완료된 것입니다.

첫 측정값은 등록 후 약 3분 뒤부터 콘솔에 나타납니다.
