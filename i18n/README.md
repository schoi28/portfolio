# 영문판

사이트는 한국어가 원문, 영어가 번역본입니다. 54편 전부 직접 작성했습니다.

```
en/docusaurus-plugin-content-docs/current/           sample_docs/ 의 영문판
en/docusaurus-plugin-content-docs-projects/current/  projects/ 의 영문판
en/docusaurus-plugin-content-pages/                  About · Resume · Contact
```

폴더 이름은 원본 폴더 이름이 아니라 **Docusaurus 플러그인 id** 를 따릅니다.
`sample_docs/` 를 `docs/` 에서 바꿔도 여기 경로는 그대로입니다.

## 구조를 맞춥니다

문장의 질은 사람이 보고, **구조가 어긋났는지는 검사기가 봅니다.**

제목 개수와 단계, 표 · 이미지 · 링크 · 안내 상자의 개수가 원문과 다르면 오류입니다.
번역하다 표 한 줄을 빠뜨리는 일이 실제로 생기기 때문입니다.

원문이 번역본보다 나중에 바뀌었으면 주의로 알립니다.
시각만 비교한 것이라 오류가 아니라 확인하라는 신호입니다.
