# Get started

Installing the app and pairing your vehicle takes about 10 minutes.

## Before you start

Have the following ready.

- Your vehicle registration document, or the 17-digit vehicle identification number (VIN)
- The pairing QR code inside the vehicle. Open the driver's door and you will find it on the inner pillar.
- The vehicle has to be somewhere it can get a signal. Pairing can fail in an underground car park.

## 1. Install the app

1. Search for `VELA Drive` in the App Store or on Google Play.
2. Install the app and open it.
3. Allow notifications. Without them you cannot receive update and service alerts.

## 2. Create an account

1. On the first screen, select **Create account**.
2. Enter your email address and a password.
3. Select the link in the verification email you receive.
4. Once verified, return to the app and sign in.

## 3. Pair your vehicle

:::info[Caution]
A vehicle is paired to one account only. A vehicle already paired to another account has to be unpaired there first.
:::

1. Select **Pair vehicle**.
2. Scan the QR code inside the vehicle. If you cannot find the code, select **Enter manually** and type the 17-digit VIN.
3. A six-digit confirmation code appears on the vehicle screen.
4. Enter that code in the app.
5. Pairing is complete when your vehicle's name and battery level appear on the home screen.

Pairing takes up to 2 minutes. Do not switch the vehicle off during that time.

## 4. Find your way around the home screen

The home screen has three areas.

| Area | Position | Contents |
| --- | --- | --- |
| Vehicle summary | Top | Battery level, range, door lock state |
| Quick controls | Middle | Locking, cabin temperature, charging, finding your vehicle |
| Alerts | Bottom | Software updates, service due, sensor cleaning |

The vehicle summary also shows the time your vehicle last communicated. An old time means the vehicle cannot currently get a signal.

## When pairing fails

| Symptom | Cause | What to do |
| --- | --- | --- |
| No confirmation code appears on the vehicle screen | The vehicle is somewhere it cannot get a signal | Move above ground and try again |
| "This vehicle is already registered" | It is paired to another account | Unpair it from the other account |
| Nothing happens after entering the code | The code's 5 minute validity has passed | Start again from step 2 |
| The QR code is not recognised | The code is damaged, or the light is poor | Enter the VIN manually |
