## Experience

### Autonomous driving solution company · Technical Writer

**January 2025 to present**

I own the English user documentation for a solution made up of five products. Starting from a state where documents were missing or scattered, I built a unified documentation set and developed the tools that produce and verify it.

- **Designed and wrote a two-tier documentation set** of a solution manual plus per-product manuals. 171 documents, 310 images, and roughly 187,000 words, of which **128 documents (75 percent) were written from scratch**
- Korean documents for internal use are maintained separately in Confluence
- Defined three reader tiers and declared the same prior-knowledge baseline across every product
- **Established three writing principles, including the glossary policy, and applied them across all products.** Restructured the full documentation set against IEC/IEEE 82079-1
- **Built an in-house static site generator** that produces web and PDF output from a single source. The output runs fully offline
- Designed a **conditional content system** on three axes (customer, internal, feature) and implemented a verification step that confirms the output matches the declared scope
- Built a **pipeline that generates the API reference from the OpenAPI specification**, with changes reported as a diff
- Wrote configuration and authoring guides so other team members can contribute to the documentation
- **Moved reviews from Google Docs to Markdown and pull requests.** Reviews that had stalled now finish within one or two days

The reasoning behind these decisions is in [Portfolio](/projects).

### Database software company · Technical Writer

**November 2023 to December 2024**

I owned the product manuals in Korean and English. Documentation was managed in a public GitHub repository.

- Responsible for the SQL reference, API user manual, replication and log analyzer manuals, tool manuals, installation guide, and release and patch notes
- As a repository collaborator, **submitted 113 pull requests with 101 merged.** Each pull request was linked to an issue tracker ticket and revised comment by comment
- **Produced the first English translation** of manuals that had none, then ran Korean and English updates as a single workflow
- Built the web manual site with MkDocs and Read the Docs
