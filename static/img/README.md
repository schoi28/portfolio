# 다이어그램

사이트 본문에 들어가는 그림입니다. 전부 손으로 쓴 SVG입니다.

제작 기준은 [`_config/diagram-guidelines.md`](../../_config/diagram-guidelines.md) 에 있습니다.
캔버스 폭, 글자 크기 넷, 색 토큰 아홉, 화살표 길이, 픽토그램 격자까지 수치로 정해 두었습니다.

## 국문·영문 쌍

```
api-command-flow.svg      국문
api-command-flow.en.svg   영문
```

**도형 좌표는 두 파일이 완전히 같습니다.** 글자만 다릅니다.
범례 시작 위치와 설명 가림 영역의 폭만 예외인데, 글자 폭에서 바로 계산되는 값이라 그렇습니다.

영문이 국문보다 약 1.3배 길어서, **영문 레이블을 먼저 쓰고 그 폭에 맞춰 상자를 설계**합니다.
국문 기준으로 만들면 영문판에서 반드시 넘칩니다.

`sensor-kit-items.svg` 는 글자가 번호와 수치뿐이라 한 파일로 두 언어를 씁니다.
