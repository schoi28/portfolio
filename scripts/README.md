# 문서 검수기

`check-docs.mjs` 한 개입니다. `_config/` 의 기준으로 `sample_docs/` 를 검사합니다.

```bash
npm run check    # 검사만
npm run build    # 검사한 뒤 빌드. 오류가 있으면 여기서 멈춥니다
```

## 검사 항목

용어와 금지 표현, 독자 수준에 맞지 않는 낱말, 절차 단계 수, 안내 상자 등급과 위치,
번호 목록 구조, 링크와 앵커의 실재 여부, 이미지 대체 텍스트, 미확인 값,
문서 간 중복 문장, 그리고 **원문과 번역본의 구조 대조**까지 17종입니다.

## 오류와 주의

**오류**는 규칙 위반이 분명한 것입니다. 빌드가 멈춥니다.
없는 링크, 잘못된 안내 상자, 원문과 번역본의 표 개수 불일치 같은 것들입니다.

**주의**는 정당한 예외가 있을 수 있는 것입니다. 보고만 하고 빌드는 진행합니다.
절차 단계 수 초과, 중복 문장처럼 사람이 봐야 판단이 되는 것들입니다.

전부 오류로 처리하면 타당한 예외 때문에 빌드가 계속 멈추고,
전부 주의로 처리하면 반드시 고쳐야 할 문제도 배포됩니다.

## 문서를 고치지 않습니다

위치와 이유만 알려 주고 수정은 사람이 합니다.
문서를 임의로 바꾸는 도구는 한 번 잘못 고치면 다시 신뢰받지 못합니다.
