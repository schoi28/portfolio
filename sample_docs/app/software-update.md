# 소프트웨어 업데이트 하기

앱을 통해 차량 소프트웨어를 업데이트할 수 있습니다. 새 소프트웨어가 준비되면 알림이 오고, 설치 시점을 직접 고르거나 예약해 둘 수 있습니다.

## 업데이트 알림 이해하기

새 소프트웨어가 준비되면 앱 알림 영역에 표시됩니다.

![업데이트가 진행되는 상태 흐름](/img/app-update-flow.svg)

:::note[참고]
내려받기는 주행 중에도 진행됩니다. 설치만 주차 상태를 요구합니다.
:::

| 상태 | 의미 | 필요한 조치 |
| --- | --- | --- |
| 다운로드 중 | 차량이 파일을 내려받는 중 | 없음. 주행 중에도 진행됩니다 |
| 설치 대기 | 다운로드 완료, 설치 시점을 기다리는 중 | 주차 후 설치를 시작하십시오 |
| 설치 중 | 차량에 적용하는 중 | 차량을 사용할 수 없습니다 |
| 완료 | 적용됨 | 없음 |

### 업데이트 종류

| 종류 | 설명 | 설치 시간 |
| --- | --- | --- |
| 일반 | 기능 개선과 버그 수정 | 15~30분 |
| 필수 | 안전 또는 보안 관련. 일정 기간 후 자동 설치됨 | 20~40분 |
| 부품 펌웨어 | 도어·에어컨 등 개별 부품의 제어 소프트웨어 | 30~60분 |

:::note[참고]
부품 펌웨어 업데이트는 차량이 완전히 멈추고 시동이 꺼진 상태에서만 진행됩니다. 다른 종류보다 시간이 오래 걸리므로, 차를 한동안 쓰지 않을 때로 예약해 두는 편이 좋습니다.
:::

## 업데이트 예약하고 설치하기

### 지금 설치하기

1. 알림에서 **소프트웨어 업데이트**를 선택합니다.
2. 변경 내용을 확인합니다.
3. **지금 설치**를 선택합니다.

설치를 시작하려면 아래 조건을 모두 만족해야 합니다.

| 조건 | 이유 |
| --- | --- |
| 주차 상태 (기어 P) | 설치 중 차량을 움직일 수 없습니다 |
| 배터리 잔량 30% 이상 | 설치 도중 전력이 부족하면 실패합니다 |
| 통신 가능한 위치 | 설치 결과를 보고해야 합니다 |

### 예약해 두기

밤 사이에 자동으로 설치되게 할 수 있습니다.

1. 업데이트 화면에서 **예약 설치**를 선택합니다.
2. 설치할 시각을 지정합니다.

예약 시각에 조건을 만족하지 않으면 설치가 미뤄지고, 다음 날 같은 시각에 다시 시도합니다.

## 설치 중 주의사항

:::info[주의]
설치 중에는 시동을 걸거나 차량을 움직이지 마십시오. 설치가 중단되면 자동으로 이전 버전으로 복구되지만, 그동안 차량을 사용할 수 없습니다.
:::

설치 중에는 다음이 제한됩니다.

- 원격 제어 명령이 실행되지 않습니다.
- 실내 온도 예약이 동작하지 않습니다.
- 디지털 키로 시동을 걸 수 없습니다.

물리 스마트키를 이용한 도어 잠금 해제는 설치 중에도 동작합니다.


설치에 실패하면 차량이 자동으로 이전 버전으로 되돌아가며, 차량은 정상적으로 사용할 수 있습니다. 알림 문구별 조치는 [문제 해결](./troubleshooting.md#업데이트가-실패했어요)을 참고하십시오.

## 이전 버전 정보 확인하기

**설정 > 소프트웨어 정보**에서 현재 버전과 최근 업데이트 이력을 확인할 수 있습니다. 각 항목을 선택하면 그 업데이트에 포함된 변경 내용을 볼 수 있습니다.
