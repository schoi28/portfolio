# VELA Drive 앱 사용 설명서

:::note[참고]
이 페이지는 제품 문서가 아니라, 그 문서를 어떻게 설계했는지에 대한 기록입니다. 실제 매뉴얼은 다음 장부터 시작합니다.
:::

## 어떻게 설계했나

| 설계 기준 | 결정 |
| --- | --- |
| **핵심 독자** | 차량을 구입한 일반 소유자 |
| **사전 지식** | 자동차 정비·소프트웨어 지식을 전제하지 않음 |
| **읽는 상황** | 휴대폰으로, 대개 특정 작업이나 문제를 해결하려고 짧게 읽음 |
| **설계 방향** | 제품 기능 이름보다 사용자의 목표·증상을 기준으로 탐색 |

### 기능 목록보다 하고 싶은 일부터 보여 주기

1장은 제품 기능 이름 대신 **무엇을 하고 싶은가**를 기준으로 시작했습니다. 사용자가 자신의 문제를 앱의 기능 이름으로 바꿔 생각하지 않아도 필요한 절차를 찾도록 하기 위해서입니다.

### 한 번에 따라 할 수 있도록 설명 묶기

휴대폰 화면으로 읽는 독자를 여러 페이지에 오가게 하지 않도록 필요한 개념과 절차를 한 장에서 연결했습니다. 반면 오류 상황은 기능별로 흩어 놓지 않고 [문제 해결하기](./troubleshooting.md)에 **증상 중심**으로 모았습니다.

### 낯선 용어와 안전 경고 최소화하기

별도의 용어집을 찾아보게 하기보다 본문에서 쉬운 표현을 사용했습니다. 예를 들어 무선으로 차량 소프트웨어를 갱신하는 방식을 가리키는 'OTA(Over-The-Air)'는 '소프트웨어 업데이트'로 설명했습니다. 다른 문서에서 쓰는 기술 용어와의 대응 관계는 제품군의 공통 용어 기준에서 관리했습니다.

차량 소유자가 수행하지 않는 하드웨어 작업의 '위험' 경고는 사용하지 않고, 되돌릴 수 없는 동작과 복구 가능한 상황을 구분해 '경고'와 '주의'를 적용했습니다.

### OEM별 화면 차이를 고려해 오래 쓸 수 있게 쓰기

VELA Drive는 완성차 회사가 자사 브랜드로 바꿔 제공할 수 있는 레퍼런스 앱입니다. 따라서 색상·로고·정확한 UI 문구처럼 달라질 수 있는 요소보다 **공통 동작과 실패 조건**에 집중했습니다.

화면이 바뀔 때마다 문서가 낡지 않도록 스크린샷에 의존하지 않고 UI 요소의 이름을 중심으로 설명했습니다.

## 이 매뉴얼의 머리말

위 판단을 적용해 만든 머리말입니다. 실제 매뉴얼에서는 아래 내용이 1장 앞에 놓입니다.

### 이 문서에 대해

VELA Drive는 차량 상태를 확인하고 원격으로 제어하는 모바일 앱입니다. 이 설명서는 앱을 설치하고 차량을 연결하는 것부터 일상적인 사용, 문제가 생겼을 때의 대처까지를 다룹니다.

| 구분 | 내용 |
| --- | --- |
| 다루는 것 | 앱 설치와 차량 연결 · 차량 상태 확인 · 원격 제어 · 디지털 키 관리 · 소프트웨어 업데이트 · 정비 알림 · 데이터 관리 |
| 다루지 않는 것 | 차량 자체의 조작 방법 · 정비 작업 · 보증과 서비스 정책 |

:::note[VELA Drive는 레퍼런스 앱입니다]
VELA는 완성차 회사(OEM)에 소프트웨어 플랫폼을 공급하는 회사이며, 차량을 직접 만들지 않습니다. VELA Drive는 OEM이 자사 브랜드로 출시하기 전에 참고하는 **레퍼런스 구현체**입니다. 각 OEM은 이 앱을 커스터마이징해 자사 전용 앱으로 출시할 수 있습니다. 기능과 화면 구성은 동일하지만 색상·이름·일부 문구는 다를 수 있습니다. 이 문서는 각색 이전의 원형 기준으로 작성했습니다.
:::

### 준비물

- VELA 플랫폼이 적용된 차량
- iOS 16 이상 또는 Android 12 이상
- 차량에 등록할 수 있는 이메일 주소

### 표기 규약

| 등급 | 이 문서에서 쓰는 경우 |
| --- | --- |
| **경고** | 디지털 키 회수, 데이터 삭제, 되돌릴 수 없는 동작 |
| **주의** | 설치 중단, 원격 잠금 시의 주의점, 복구 가능한 상황 |
| **참고** | 알아 두면 편한 정보 |

이 문서에는 **'위험' 등급이 나오지 않습니다.** 차량 소유자는 하드웨어를 직접 만지지 않기 때문입니다.

| 표기 | 뜻 |
| --- | --- |
| **굵은 글씨** | 앱 화면에 표시된 버튼이나 메뉴의 이름 |
| **설정 > 차량** | 메뉴를 차례로 선택하는 경로 |
