# Sample Docs

**VELA는 완성차 회사에 차량용 소프트웨어를 공급하는 가상의 기업입니다.** 이곳에는 VELA의 모바일 앱, 차량 API, 무선 업데이트 운영 콘솔, 센서 킷을 위해 작성한 네 종류의 기술 문서를 공개했습니다.

각 문서는 **독자가 하는 일과 사전 지식에 맞춰** 다른 방식으로 구성했습니다.

:::note[가상 제품 안내]
VELA와 아래 제품들은 문서 설계를 보여 주기 위해 만든 가상의 회사와 제품입니다. 실제 제품이나 조직을 설명하는 문서는 아닙니다.
:::

## 이 탭을 읽는 방법

각 제품을 선택하면 먼저 **설계 노트**가 나옵니다. 그다음 **1장부터는 실제 사용자를 위한 매뉴얼**이 시작됩니다.

| 구분 | 무엇을 볼 수 있나 | 추천 독자 |
| --- | --- | --- |
| **설계 노트** | 누구를 위해 썼고, 목차·표현·정보 배치를 왜 그렇게 결정했는지 | 문서 설계 역량을 확인하려는 포트폴리오 방문자 |
| **1장부터의 매뉴얼** | VELA 제품을 실제로 사용한다고 가정하고 작성한 개념·절차·레퍼런스 | 문서의 완성도와 사용성을 확인하려는 방문자 |

**빠르게 살펴보려면** 아래 표에서 관심 있는 제품을 선택해 설계 노트를 읽은 뒤, 실제 매뉴얼의 한두 장을 비교해 보세요.

## VELA는 어떤 회사인가

VELA는 자동차를 직접 만들지 않습니다. 자동차 회사가 차를 개발하고 판매할 수 있도록 **차량에 연결되는 소프트웨어와 관련 제품**을 공급합니다.

개발·검증 차량에 센서를 설치하고, 개발자는 API로 차량 데이터를 사용합니다. 차량이 출시된 후에는 운영자가 소프트웨어를 무선으로 배포하고, 차량 소유자는 모바일 앱으로 차량 상태를 확인합니다. **네 제품은 이처럼 하나의 차량 서비스 안에서 연결됩니다.**

이 차이를 직접 확인하는 것이 Sample Docs의 핵심입니다.
