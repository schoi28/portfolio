# 전원 넣고 점검하기

배선을 마친 뒤 처음으로 전원을 넣고, 모든 센서가 인식되는지 확인합니다.

:::info[주의]
몰딩과 커버를 복원하기 **전에** 이 장을 수행하십시오. 문제가 있으면 다시 분해해야 합니다.
:::

## 준비물

| 항목 | 규격 |
| --- | --- |
| 멀티미터 | 저항·전압 측정 |
| 노트북 | 로컬 진단 화면 접속용. 브라우저 필요 |

- **작업 조건:** 1명 · 약 30분 · 몰딩과 커버를 복원하기 전
- **선행 작업:** [5. 배선하기](./wiring.md) 완료

## 1. 전원 넣기 전 점검하기

| 확인 | 방법 |
| --- | --- |
| 전원 극성 | 멀티미터로 `PWR` 커넥터 확인 |
| 단락 여부 | +12V와 GND 사이 저항 측정. 1 kΩ 이상 |
| 커넥터 체결 | 모든 포트 눈으로 확인 |
| 남은 공구 | 작업 공간 정리 |

:::warning[경고]
단락 확인을 건너뛰지 마십시오. 배선이 잘못된 상태에서 배터리를 연결하면 하네스가 손상됩니다.
:::

## 2. 전원 넣기

1. 차량 12V 배터리 음극 단자를 다시 연결합니다.
2. 차량 시동을 겁니다.
3. 인터페이스 박스의 상태 LED를 관찰합니다.

정상적인 부팅은 아래 순서를 따릅니다.

| 시각 | LED 상태 | 진행 상황 |
| --- | --- | --- |
| 0초 | 꺼짐 → 흰색 켜짐 | 전원 넣음 |
| 3초 | 흰색 깜박임 | 자체 점검 중 |
| 15초 | 흰색 깜박임 유지 | 센서 인식 중 |
| 30~45초 | 초록색 켜짐 | 정상. 모든 센서가 인식됨 |

45초가 지나도 초록색이 되지 않으면 문제가 있는 것입니다.

## 3. 상태 LED 읽는 법

![인터페이스 박스 상태 LED의 색상별 의미](/img/sensor-led-states.svg)

| LED | 의미 | 조치 |
| --- | --- | --- |
| 흰색 깜박임 | 부팅 중 또는 링크 대기 | 45초까지 기다립니다 |
| 초록색 켜짐 | 정상 | 다음 단계로 진행합니다 |
| 주황색 깜박임 | 센서 일부가 인식되지 않음 또는 시간 동기화 실패 | 4단계 진단을 실행합니다 |
| 빨간색 켜짐 | 전원 이상 또는 하드웨어 고장 | 즉시 전원을 차단합니다 |
| 꺼짐 | 전원이 들어오지 않음 | 아래 "전원이 들어오지 않을 때"를 보십시오 |

:::warning[경고]
빨간색이 켜지면 즉시 전원을 끊으십시오. 전기가 계속 흐르면 손상이 커집니다.
:::

### 전원 끊는 방법

이 킷에는 별도의 전원 스위치가 없습니다. **차량 12V 배터리의 음극(−) 단자를 분리**하면 전원이 끊깁니다.

### 전원이 들어오지 않을 때

시동을 걸었는데도 LED가 계속 꺼져 있으면 전원이 공급되지 않는 것입니다. 아래 순서로 확인하십시오.

1. 차량 12V 배터리의 음극 단자를 분리합니다. **전기가 흐르는 상태에서 커넥터를 만지지 마십시오.**
2. 인출 지점에 설치한 15 A 퓨즈가 끊어지지 않았는지 확인합니다.
3. `PWR` 커넥터가 인터페이스 박스에 끝까지 꽂혀 있는지 확인합니다. 딸깍 소리가 나야 체결된 것입니다.
4. 음극 단자를 다시 연결하고 시동을 겁니다.

그래도 LED가 꺼져 있으면 [문제 해결하기](./troubleshooting.md#증상별-진단표)의 "전원이 들어오지 않음" 항목을 보십시오.

## 4. 초기 진단 실행하기

노트북을 `DIAG` 포트에 연결해 실행합니다.

1. USB-C 케이블로 노트북과 `DIAG` 포트를 연결합니다.
2. 브라우저에서 `http://192.168.10.1`에 접속합니다.
3. **초기 진단 실행**을 선택합니다.

진단은 약 2분이 걸리며 아래 항목을 확인합니다.

| 항목 | 합격 기준 |
| --- | --- |
| 전원 전압 | 11.0~15.0 V |
| 라이다 링크 | 연결됨, 포인트 수신 확인 |
| 카메라 링크 4채널 | 4채널 모두 영상 수신 |
| 카메라 위치 매핑 | 각 채널의 영상이 지정 위치와 일치 |
| 시간 동기화 | 오차 10 마이크로초 이하 |
| 이더넷 출력 | 중앙 연산 장치와 링크 확인 |
| 온도 | 인터페이스 박스 내부 70 °C 이하 |

### 카메라 위치 매핑 확인

진단 화면에 4채널 영상이 동시에 표시됩니다. 각 영상이 실제 위치와 맞는지 직접 확인하십시오.

:::info[주의]
자동 진단은 영상이 들어오는지만 확인하고, 어느 카메라의 영상인지는 구분하지 못합니다. 아래 절차로 **진단 화면을 직접 보면서 네 영상의 위치를 확인하십시오.** 케이블을 바꿔 꽂은 실수를 여기서 잡지 못하면 캘리브레이션 단계에서 원인을 찾기 어렵습니다.
:::

1. 차량 앞에 사람이 서서 손을 듭니다.
2. `CAM1` 영상에 그 사람이 보이는지 확인합니다.
3. 후방·좌측·우측도 같은 방법으로 확인합니다.

## 5. 진단 실패에 대응하기

| 결과 | 원인 | 조치 |
| --- | --- | --- |
| 전원 전압 낮음 | 배선 규격 부족 또는 접촉 불량 | 배선 굵기와 단자가 제대로 조여졌는지 확인 |
| 라이다 링크 없음 | 커넥터가 덜 끼워짐 | 잠금 링을 다시 끼움 |
| 카메라 1채널 없음 | 해당 커넥터 문제 | 커넥터를 다시 끼우고 진단을 다시 실행 |
| 카메라 위치 뒤바뀜 | 커넥터를 잘못 꽂음 | 색상표대로 다시 연결 |
| 시간 동기화 실패 | 이더넷 케이블 품질 또는 `SYNC` 배선 | 차폐 케이블 사용 여부 확인 |
| 온도 높음 | 통풍 부족 | 인터페이스 박스 주변 확보 |

문제를 해결한 뒤 진단을 다시 실행합니다. 모든 항목이 합격이면 다음 단계로 진행합니다.

## 6. 몰딩과 커버 다시 끼우기

진단이 모두 합격한 뒤에 다시 끼웁니다.

1. 케이블이 몰딩에 눌리지 않는지 확인하면서 떼어낸 역순으로 끼웁니다.
2. 다 끼운 뒤 진단을 **한 번 더** 실행합니다. 이 과정에서 커넥터가 빠질 수 있습니다.
