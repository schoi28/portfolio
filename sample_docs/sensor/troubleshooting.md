# 문제 해결하기

겪고 있는 증상으로 원인을 찾는 장입니다. **증상별 진단표, 오류 코드 목록, 지원 조직에 보낼 진단 스냅숏 만드는 법**이 들어 있습니다.

:::warning[경고]
점검을 위해 커넥터를 분리하기 전에 반드시 전원을 차단하십시오.
:::

## 증상별 진단표

### 전원이 들어오지 않음

| 확인 순서 | 확인 항목 | 정상 기준 | 이상 시 조치 |
| --- | --- | --- | --- |
| 1 | LED 상태 | 켜짐 | 꺼져 있으면 다음으로 |
| 2 | 퓨즈 | 도통됨 | 끊어졌으면 단락 원인 확인 후 교체 |
| 3 | `PWR` 커넥터 전압 | 11.0~15.0 V | 전압 없으면 인출점 확인 |
| 4 | 커넥터 체결 | 잠김 | 다시 끼움 |
| 5 | 접지 저항 | 0.1 Ω 이하 | 접지점 재작업 |

:::warning[경고]
퓨즈가 반복해서 끊어진다면 단락이 있는 것입니다. 더 큰 용량의 퓨즈로 교체하지 마십시오.
:::

### LED가 주황색으로 깜박임

일부 센서가 인식되지 않거나 시간 동기화에 실패한 상태입니다.

| 확인 순서 | 확인 항목 | 조치 |
| --- | --- | --- |
| 1 | 진단 실행 | 어느 항목이 실패했는지 확인 |
| 2 | 실패한 센서의 커넥터 | 다시 끼움 후 재진단 |
| 3 | 케이블 손상 | 눈으로 확인하고 손상됐으면 교체 |
| 4 | 시간 동기화 오차 | 10 µs 초과 시 차폐 케이블 확인 |
| 5 | 센서 자체 상태 | `fault`면 모듈 교체 검토 |

### 특정 카메라만 영상이 없음

| 원인 | 확인 방법 | 조치 |
| --- | --- | --- |
| 커넥터가 덜 끼워짐 | 해당 포트 눈으로 확인 | 다시 끼움 |
| 케이블 단선 | 다른 정상 포트에 바꿔 연결 | 영상이 나오면 케이블 문제 |
| 카메라 고장 | 정상 케이블로 교체 후에도 없음 | 카메라 교체 |
| 포트 고장 | 정상 카메라를 연결해도 없음 | 인터페이스 박스 교체 |

정상 포트와 바꿔 연결해 보는 것이 원인을 가리는 가장 빠른 방법입니다.

### 카메라 위치가 뒤바뀌어 보임

케이블을 잘못 연결한 경우입니다.

1. 각 카메라 케이블의 커넥터 색상을 확인합니다.
2. [배선하기](./wiring.md#3-데이터-케이블-연결하기)의 색상표대로 다시 연결합니다.
3. 진단에서 [위치 매핑 확인](./power-check.md#카메라-위치-매핑-확인)을 수행합니다.
4. 캘리브레이션을 다시 수행합니다.

### 캘리브레이션이 반복 실패함

| 실패 항목 | 확인 | 조치 |
| --- | --- | --- |
| 타깃 미검출 | 보드 위치·조도 | 배치 거리와 조도를 재확인 |
| 라이다 각도 편차 초과 | 장착 기울기 | 수평계로 재측정, 재장착 |
| 재투영 오차 초과 | 렌즈 오염·각도 | 청소 후 재시도 |
| 정합 오차 초과 | 카메라 위치 매핑 | 케이블 연결 재확인 |
| 자세 추정 미수렴 | 주행 조건 | 조건에 맞는 도로에서 재주행 |
| 타이어 공기압 | 규정값 여부 | 규정값으로 조정 후 재시도 |

타이어 공기압은 자주 간과되는 원인입니다. 차체 높이가 달라지면 모든 센서의 기준 위치가 어긋납니다.

### 주행 중 간헐적으로 센서가 끊김

진동에 의한 접촉 불량일 가능성이 높습니다.

| 확인 | 방법 |
| --- | --- |
| 커넥터 여유 길이 | 커넥터 근처 100 mm에 여유가 있는지 |
| 케이블 고정 | 300 mm 이하 간격으로 고정되었는지 |
| 브래킷 토크 | 규정 토크 유지 여부 |
| 커넥터 잠금 | 잠금 링이 완전히 체결되었는지 |

케이블이 팽팽하게 당겨진 상태로 고정되어 있으면 진동이 커넥터에 그대로 전달됩니다.

### 우천 시에만 성능이 떨어짐

| 원인 | 조치 |
| --- | --- |
| 전방 카메라가 와이퍼 범위 밖 | 장착 위치 재조정 |
| 광학창 발수 성능 저하 | 청소 후 재확인 |
| 실런트 손상으로 수분 유입 | 실런트 재시공 |

## 오류 코드

진단 화면에 표시되는 코드입니다.

### 전원·하드웨어

| 코드 | 의미 | 조치 |
| --- | --- | --- |
| `HW_001` | 입력 전압 범위 초과 | 배선·전압 확인 |
| `HW_002` | 내부 온도 초과 | 통풍 확보 |
| `HW_003` | 인터페이스 박스 자체 점검 실패 | 모듈 교체 |
| `HW_004` | 전원 서지 감지 | 배선 점검 |

### 센서 링크

| 코드 | 의미 | 조치 |
| --- | --- | --- |
| `LNK_101` | 라이다 링크 없음 | 커넥터 다시 끼움 |
| `LNK_102` | 라이다 데이터 손실률 초과 | 케이블 품질 확인 |
| `LNK_201` | 카메라 채널 신호 없음 | 해당 커넥터 확인 |
| `LNK_202` | 카메라 프레임 드롭 | 케이블 길이·품질 확인 |
| `LNK_301` | 시간 동기화 실패 | 차폐 케이블 확인 |
| `LNK_302` | 시간 동기화 오차 초과 | `SYNC` 배선 확인 |

### 센서 상태

| 코드 | 의미 | 조치 |
| --- | --- | --- |
| `SEN_401` | 라이다 광학창 오염 | 청소 |
| `SEN_402` | 라이다 포인트 수 부족 | 청소 후 재확인, 회복 안 되면 교체 |
| `SEN_403` | 카메라 노출 이상 | 렌즈 확인 |
| `SEN_404` | 카메라 초점 이상 | 모듈 교체 |
| `SEN_405` | 센서 내부 온도 초과 | 직사광선 노출 확인 |

### 캘리브레이션

| 코드 | 의미 | 조치 |
| --- | --- | --- |
| `CAL_501` | 타깃 검출 실패 | 보드 배치·조도 확인 |
| `CAL_502` | 각도 편차 허용 범위 초과 | 재장착 |
| `CAL_503` | 재투영 오차 초과 | 렌즈 청소 후 재시도 |
| `CAL_504` | 정합 오차 초과 | 카메라 위치 매핑 확인 |
| `CAL_505` | 동적 캘리브레이션 값이 수렴하지 않음 | 주행 조건을 다시 확인 |
| `CAL_506` | 캘리브레이션 데이터 손상 | 정적 캘리브레이션부터 다시 수행 |

## 진단 스냅숏 보내기

현장에서 해결되지 않으면 진단 스냅숏을 생성해 지원 조직에 전달합니다.

1. 진단 화면에서 **진단 스냅숏 생성**을 선택합니다.
2. 생성이 끝날 때까지 기다립니다. 3분에서 10분이 걸리며, 파일 크기는 보통 500 MB에서 2 GB입니다.
3. 생성이 끝나면 **노트북에 내려받기**를 선택합니다.

차량이 통신되는 곳에 있으면 스냅숏이 서버로 자동 전송됩니다. 이때는 내려받지 않아도 됩니다.

API로 스냅숏을 받는 방법은 [VELA Vehicle API · 센서](../api/sensors.md#진단-스냅숏-내려받기)를 참고하십시오.
