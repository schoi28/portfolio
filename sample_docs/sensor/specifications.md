# 사양 확인하기

현장에서 찾아보는 값을 모아 둔 장입니다. **LR-40 라이다와 CM-20 카메라의 성능·광학·전기 사양, 인터페이스 박스 규격, 킷 구성, 장착 허용 오차, 조임 토크, 캘리브레이션 합격 기준**이 들어 있습니다. 장착이나 점검 중에 **정상 범위와 허용 오차를 확인해야 할 때** 이 장을 보십시오.

## LR-40 라이다

### 성능

| 항목 | 값 |
| --- | --- |
| 측정 방식 | 회전형 ToF |
| 채널 수 | 40 |
| 수평 시야각 | 360° |
| 수직 시야각 | 40° (−25° ~ +15°) |
| 각 분해능 (수평) | 0.1° |
| 각 분해능 (수직) | 1.0° |
| 최대 측정 거리 | 200 m (반사율 80% 기준) |
| 최소 측정 거리 | 0.3 m |
| 거리 정확도 | ± 2 cm |
| 포인트 생성률 | 최대 1,200,000 points/s |
| 회전 속도 | 10 Hz 또는 20 Hz |

### 광학

| 항목 | 값 |
| --- | --- |
| 파장 | 905 nm |
| 레이저 등급 | Class 1M (IEC 60825-1) |

:::danger[위험]
Class 1M은 맨눈으로 보는 정상 사용 조건에서는 안전하지만, **확대 광학 기기로 빔을 들여다보면 안전하지 않다**는 등급입니다. 루페, 쌍안경, 망원 렌즈, 현미경을 광학창에 대고 보지 마십시오. 분해해 내부 광학계를 직접 노출시킨 상태도 같습니다.
:::

| 항목 | 값 |
| --- | --- |
| 입력 전압 | 9~32 V DC |
| 소비 전력 | 평균 22 W, 최대 30 W |
| 인터페이스 | 10GBASE-T 이더넷 |
| 커넥터 | M12 X-coded |
| 크기 | 110 × 110 × 78 mm |
| 무게 | 1.15 kg |
| 보호 등급 | IP67 |
| 동작 온도 | −40 ~ +65 °C |
| 보관 온도 | −50 ~ +85 °C |
| 내진동 | 5~2000 Hz, 3 Grms |

## 인터페이스 박스

| 항목 | 값 |
| --- | --- |
| 입력 전압 | 9~16 V DC |
| 소비 전력 | 평균 18 W, 최대 45 W (전 센서 동작 시) |
| 퓨즈 권장 용량 | 15 A |
| 카메라 입력 | GMSL2 × 4 |
| 라이다 입력 | 10GBASE-T × 1 |
| 출력 | 1000BASE-T1 × 1 |
| 시간 동기화 | IEEE 802.1AS (gPTP) |
| 동기화 정확도 | ± 1 µs 이내 |
| 외부 시간원 | PPS + NMEA (옵션) |
| 진단 포트 | USB-C |
| 크기 | 180 × 140 × 45 mm |
| 무게 | 780 g |
| 보호 등급 | IP54 |
| 동작 온도 | −20 ~ +70 °C |

:::info[주의]
인터페이스 박스는 IP54입니다. 라이다·카메라와 달리 침수에 견디지 못하므로 실내(트렁크)에만 장착하십시오.
:::
