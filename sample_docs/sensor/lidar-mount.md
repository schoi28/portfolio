# 라이다 장착하기

LR-40 라이다를 루프 중앙에 고정합니다.

:::danger[위험]
전원이 켜져 있는 동안에는 **확대경이나 확대 기능이 있는 카메라로 광학창을 들여다보지 마십시오**(Class 1M). 작업 전 차량 배터리 음극 단자가 분리되어 있는지 확인하십시오.
:::

## 준비물

| 항목 | 규격 |
| --- | --- |
| 토크 렌치 | 5~25 N·m |
| 육각 렌치 | 5 mm |
| 수평계 | 디지털 권장, 분해능 0.1° |
| 탈지제 | 이소프로필 알코올 |
| 실런트 | 킷에 포함 |

- **작업 조건:** 2명 · 약 40분 · 차량 배터리 음극 단자 분리 상태
- **선행 작업:** [2. 설치 계획 세우기](./planning.md)에서 브래킷과 케이블 경로 결정

## 1. 브래킷 고정하기

:::warning[경고]
한 번에 최종 토크로 조이지 마십시오. 브래킷이 기울어 고정되면 기울기 허용 오차를 맞출 수 없습니다.
:::

1. 루프 장착면을 탈지제로 닦고 완전히 건조시킵니다.
2. [설치 계획](./planning.md#차종별-브래킷-선택)에서 선택한 브래킷을 루프 중앙에 놓습니다.
3. 차량 중심선과 브래킷 중심을 맞춥니다. 좌우 편차는 **±5 mm** 이내여야 합니다.
4. 브래킷의 볼트 4개를 대각선 순서로 조입니다.

| 조임 순서 | 토크 |
| --- | --- |
| 1차 (전체) | 5 N·m |
| 2차 (전체) | 12 N·m |
| 최종 (전체) | 18 N·m ± 2 |

## 2. 라이다 본체 올리기

1. 라이다 본체의 커넥터 방향을 **차량 후방**으로 향하게 놓습니다.
2. 브래킷의 가이드 핀에 본체를 맞춰 내려놓습니다.
3. 고정 볼트 4개를 손으로 조입니다. 아직 최종 토크로 조이지 마십시오.

## 3. 기울기 맞추기

라이다의 기울기는 인식 성능에 직접 영향을 줍니다.

:::info[주의]
허용 오차를 벗어난 상태로 진행하면 캘리브레이션이 실패합니다. 캘리브레이션 단계에서 소프트웨어로 보정할 수 있는 범위는 ±0.5° 이내입니다.
:::

1. 차량이 수평인 바닥에 있는지 확인합니다.
2. 라이다 상단의 기준면에 수평계를 올립니다.
3. 아래 허용 오차 안에 들어오도록 조정합니다.

   | 축 | 목표 | 허용 오차 |
   | --- | --- | --- |
   | 피치 (전후 기울기) | 0.0° | ± 0.3° |
   | 롤 (좌우 기울기) | 0.0° | ± 0.3° |
   | 요 (수평 회전) | 차량 중심선과 일치 | ± 0.5° |

4. 허용 오차 안에 들어오면 고정 볼트를 대각선 순서로 조입니다.

   | 조임 순서 | 토크 |
   | --- | --- |
   | 1차 | 4 N·m |
   | 최종 | 9 N·m ± 1 |

5. 조인 뒤 수평계로 다시 측정합니다. 조이는 과정에서 틀어질 수 있습니다.

## 4. 케이블 연결하기

1. 이더넷 케이블을 라이다 후면 커넥터에 연결합니다.
2. 커넥터의 잠금 링을 시계 방향으로 돌려 고정합니다. **딸깍** 소리가 나야 합니다.
3. 케이블에 물이 고이지 않도록 커넥터 아래쪽으로 처지는 구간(드립 루프)을 만듭니다.
4. [설치 계획](./planning.md#케이블-경로-계획)에서 정한 경로로 케이블을 통과시킵니다.

## 5. 방수 처리하기

1. 브래킷과 루프가 맞닿는 둘레에 실런트를 도포합니다.
2. 볼트 머리 부분에도 실런트를 덮습니다.
3. 케이블이 루프를 관통하는 부분에 그로밋을 끼우고 실런트로 마감합니다.

:::warning[경고]
실런트가 경화되기 전에 세차하지 마십시오. 경화에는 24시간이 필요합니다.
:::

## 확인 항목

다음 단계로 넘어가기 전에 확인하십시오.

| 확인 | 기준 |
| --- | --- |
| 좌우 중심 정렬 | ± 5 mm 이내 |
| 피치·롤 | ± 0.3° 이내 |
| 요 | ± 0.5° 이내 |
| 볼트 토크 | 브래킷 18 N·m, 본체 9 N·m |
| 커넥터 잠금 | 잠금 링 체결 확인 |
| 실런트 도포 | 둘레 전체, 끊김 없음 |
| 광학창 상태 | 지문·이물질 없음 |

광학창에 지문이 묻었다면 마른 극세사 천으로 닦으십시오. 용제를 사용하면 코팅이 손상됩니다.
