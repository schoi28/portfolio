# VELA Sense 설치 가이드

:::note[참고]
이 페이지는 제품 문서가 아니라, 그 문서를 어떻게 설계했는지에 대한 기록입니다. 실제 매뉴얼은 다음 장부터 시작합니다.
:::

## 어떻게 설계했나

| 설계 기준 | 결정 |
| --- | --- |
| **핵심 독자** | 차량에 센서 킷을 직접 장착·점검하는 현장 엔지니어 |
| **사전 지식** | 기구·배선 작업에 익숙하지만 소프트웨어·네트워크 지식은 제한적이라고 가정 |
| **읽는 상황** | 조명과 조작이 제한된 현장에서 태블릿으로 작업 중 확인 |
| **설계 방향** | 실제 작업 순서를 따르고, 수치·위험 정보를 필요한 위치에 제시 |

### 실제 장착·검증 순서대로 구성하기

장착, 배선, 전원 인가, 캘리브레이션으로 이어지는 **물리적 작업 순서**를 따라 장을 구성했습니다. 현장에서 한 작업씩 확인할 수 있도록 절을 짧게 나누고 표를 적극적으로 사용했습니다.

치수·토크·합격 기준은 작업 절차에서 반복하지 않고 [사양 확인하기](./specifications.md)에 모았습니다. 캘리브레이션은 합격 기준을 자의적으로 완화하지 않도록 필요한 개념과 절차를 함께 설명했습니다.

### 안전 경고를 작업 직전에 배치하기

위험 안내를 문서 앞부분에 한 번 모아 놓으면 실제 작업 중 놓칠 수 있습니다. 그래서 **해당 작업을 시작하기 직전에 필요한 경고를 배치**하고, 필요할 때는 반복했습니다.

신체에 중대한 위해가 발생할 수 있는 상황에만 '위험'을 사용하고, 장비 손상이나 복구 가능한 문제는 '경고'와 '주의'로 구분했습니다. 네 문서 세트 중 신체 위험을 직접 다루는 이 가이드에만 '위험' 등급을 적용했습니다.

### 익숙하지 않은 기술과 후속 작업 연결하기

기계 작업에 숙련된 독자라도 GMSL2, PTP, 외재 파라미터 같은 기술 용어는 낯설 수 있습니다. 본문을 길게 늘이지 않도록 용어집을 두고 필요한 첫 지점에서 연결했습니다.

설치·캘리브레이션 후 센서 상태를 확인할 때는 [Vehicle API](../api/intro.md), 차량 소유자가 센서 청소 알림을 확인할 때는 [VELA Drive 앱](../app/intro.md)으로 이어지도록 관련 문서를 연결했습니다.

## 이 매뉴얼의 머리말

위 판단을 적용해 만든 머리말입니다. 실제 매뉴얼에서는 아래 내용이 1장 앞에 놓입니다.

### 이 문서에 대해

VELA Sense 레퍼런스 센서 킷을 차량에 장착하고, 배선하고, 캘리브레이션해 정상 동작을 확인하기까지의 전 과정을 다룹니다.

| 구분 | 내용 |
| --- | --- |
| 다루는 것 | 장착 위치 선정 · 기구 장착 · 배선 · 전원 넣기 · 캘리브레이션 · 정기 점검 · 현장 진단 |
| 다루지 않는 것 | 센서 데이터의 활용(→ [VELA Vehicle API](../api/intro.md)) · 차량 플랫폼 소프트웨어 설치 · OEM 양산 차량의 센서 구성 |
| 적용 대상 | VELA Sense 킷 R2 (LR-40 라이다 · CM-20 카메라 · 인터페이스 박스 IB-2) |
| 작업 환경 | 개발·검증 차량. 양산 차량에는 적용하지 않습니다 |

### 대상 독자

차량에 하드웨어를 직접 장착하는 현장 엔지니어를 기준으로 썼습니다. **자율주행 시스템에 대한 사전 지식은 전제하지 않습니다.**

| 역할 | 하는 일 | 먼저 읽을 곳 |
| --- | --- | --- |
| **현장 설치 엔지니어** | 차량에 센서를 장착하고 배선한다 | [VELA Sense란](./overview.md) → [설치 계획 세우기](./planning.md) |
| **검증 엔지니어** | 캘리브레이션을 수행하고 합격 여부를 판정한다 | [캘리브레이션하기](./calibration.md) · [사양 확인하기](./specifications.md) |
| **차량 관리 담당자** | 장착된 킷을 정기 점검하고 모듈을 교체한다 | [점검하고 관리하기](./maintenance.md) · [문제 해결하기](./troubleshooting.md) |
| **통합 담당 개발자** | 센서 상태를 소프트웨어에서 읽는다 | [VELA Vehicle API · 센서 상태 조회하기](../api/sensors.md) |

전제하는 숙련도는 다음과 같습니다.

- 차량 내장재를 떼었다 다시 끼우는 작업, 토크 렌치 사용, 하네스 배선에 숙련되어 있을 것
- 멀티미터로 도통과 단락을 확인할 수 있을 것
- 노트북으로 설정 도구를 실행할 수 있을 것. **명령줄 사용은 전제하지 않습니다.**

### 표기 규약

#### 안내 상자

| 등급 | 이 문서에서 쓰는 경우 |
| --- | --- |
| **위험** | 레이저 광원, 에어백 전개 경로, 화재, 사망이나 중상에 이르는 경우 |
| **경고** | 12V 전기 작업, 하네스 손상, 모듈 교체 후 미보정, 되돌릴 수 없는 손상 |
| **주의** | 허용 오차 이탈, 재작업이 필요한 실수, 복구 가능한 오류 |
| **참고** | 알아 두면 작업이 수월해지는 정보 |

네 문서 세트에서 공통으로 쓰는 등급 기준 중, 이 설치 가이드는 신체 위험에 해당하는 '위험' 등급도 사용합니다.

#### 글자 표기

| 표기 | 뜻 |
| --- | --- |
| **굵은 글씨** | 화면이나 장비에 표시된 요소의 이름 |
| **설정 > 센서** | 메뉴를 차례로 선택하는 경로 |
| `LR-40` | 모델명, 커넥터 이름, 파일 이름 |
| 18 N·m ± 2 | 값과 허용 오차. 허용 오차가 적힌 수치는 반드시 측정해 확인합니다 |
