# 배선하기

센서 케이블을 인터페이스 박스에 연결하고 전원을 배선합니다.

:::danger[위험]
전원 배선 작업 전 차량 12V 배터리의 음극 단자가 분리되어 있는지 다시 확인하십시오. 전기가 흐르는 상태에서 작업하면 단락으로 화재가 발생할 수 있습니다.
:::

## 준비물

| 항목 | 규격 |
| --- | --- |
| 토크 렌치 | 5~25 N·m |
| 멀티미터 | 저항·전압 측정 |
| 케이블 타이 | 내열 |

- **작업 조건:** 1명 · 약 90분 · 차량 배터리 음극 단자 분리 상태
- **선행 작업:** [4. 카메라 장착하기](./camera-mount.md) 완료, 몰딩과 커버를 떼어낸 상태

## 구성도

![센서와 인터페이스 박스, 중앙 연산 장치의 배선 구성](/img/sensor-wiring.svg)

:::note[참고]
카메라는 전원선이 따로 없습니다. 인터페이스 박스가 동축 케이블 한 가닥으로 영상과 전원을 함께 보냅니다.
:::

카메라는 동축 케이블 하나로 영상과 전원을 함께 전달받습니다. 별도의 전원선이 필요하지 않습니다.

## 1. 인터페이스 박스 고정하기

:::warning[경고]
인터페이스 박스를 스페어타이어 공간 바닥에 두지 마십시오. 침수 시 손상됩니다.
:::

1. 트렁크 좌측 벽면에 브래킷을 볼트 4개로 고정합니다. 토크는 **8 N·m**입니다.
2. 인터페이스 박스를 브래킷에 끼우고 잠금 레버를 내립니다.
3. 통풍구가 막히지 않는지 확인합니다. 주변 100 mm 이상을 비워 두십시오.

## 2. 커넥터 핀맵

인터페이스 박스 후면의 커넥터 배치입니다.

| 포트 | 종류 | 연결 대상 |
| --- | --- | --- |
| `PWR` | 2핀 | 차량 12V 전원 |
| `LIDAR` | RJ45 (차폐) | LR-40 라이다 |
| `CAM1`~`CAM4` | FAKRA 동축 | 카메라 4대 |
| `ETH-OUT` | RJ45 (차폐) | 중앙 연산 장치 |
| `SYNC` | 4핀 | 시간 동기화 (옵션) |
| `DIAG` | USB-C | 진단용 노트북 |

### PWR 커넥터 핀 배치

| 핀 번호 | 색상 | 신호 | 규격 |
| --- | --- | --- | --- |
| 1 | 빨강 | +12V | 최대 8 A |
| 2 | 검정 | GND | 없음 |

### SYNC 커넥터 핀 배치

외부 GNSS 시간원을 사용할 때만 연결합니다. 사용하지 않으면 인터페이스 박스가 자체 시간원으로 동작합니다.

| 핀 번호 | 신호 | 설명 |
| --- | --- | --- |
| 1 | PPS+ | 초당 1펄스 신호 |
| 2 | PPS− | 신호 접지 |
| 3 | NMEA | 시각 정보 |
| 4 | GND | 접지 |

## 3. 데이터 케이블 연결하기

:::info[주의]
카메라 커넥터를 잘못 꽂으면 전기적으로는 정상 동작하지만 위치가 뒤바뀐 채로 인식됩니다. 캘리브레이션 단계에서 원인을 찾기 어려우므로 여기서 반드시 확인하십시오.
:::

1. 라이다 이더넷 케이블을 `LIDAR` 포트에 연결합니다.
2. 카메라 케이블을 색상에 맞춰 `CAM1`~`CAM4`에 연결합니다.

   | 커넥터 색상 | 포트 | 위치 |
   | --- | --- | --- |
   | 파란색 | `CAM1` | 전방 |
   | 초록색 | `CAM2` | 후방 |
   | 노란색 | `CAM3` | 좌측 |
   | 흰색 | `CAM4` | 우측 |

3. `ETH-OUT`을 중앙 연산 장치의 확장 이더넷 포트에 연결합니다.

## 4. 전원 배선하기

### 전원 인출 위치

| 항목 | 값 |
| --- | --- |
| 인출 지점 | 트렁크 정션 박스의 상시 전원 단자 |
| 퓨즈 용량 | 15 A |
| 퓨즈 위치 | 인출 지점에서 300 mm 이내 |
| 배선 규격 | 2.0 sq 이상 |

:::danger[위험]
퓨즈를 생략하거나 용량이 큰 퓨즈를 사용하지 마십시오. 단락 시 하네스가 발화할 수 있습니다.
:::

1. 정션 박스의 상시 전원 단자에서 전원을 인출합니다.
2. 인출 지점에서 300 mm 이내에 15 A 퓨즈 홀더를 설치합니다.
3. 전원선을 `PWR` 커넥터 1번 핀에 연결합니다.

### 접지

:::warning[경고]
차체에 새로 구멍을 뚫어 접지점을 만들지 마십시오. 부식이 시작되고 방청 보증이 무효가 됩니다.
:::

1. 접지선을 차체의 순정 접지점에 연결합니다.
2. 접지점의 도장을 제거하고 금속면을 노출시킵니다.
3. 볼트를 **9 N·m**으로 조입니다.

| 확인 | 기준 |
| --- | --- |
| 접지 저항 | 0.1 Ω 이하 |
| 접지점 | 순정 접지점 사용 (신규 타공 금지) |

## 5. 케이블 고정하기

1. 모든 케이블을 순정 하네스에 케이블 타이로 고정합니다. 간격은 **300 mm 이하**입니다.
2. 커넥터 근처 100 mm 구간은 고정하지 않고 여유를 둡니다.
3. 날카로운 판금 모서리를 지나는 구간에는 보호 튜브를 씌웁니다.

## 확인 항목

배터리를 다시 연결하기 전에 확인하십시오.

| 확인 | 기준 |
| --- | --- |
| 전원 극성 | 1번 빨강(+), 2번 검정(GND) |
| 퓨즈 | 15 A, 인출점 300 mm 이내 |
| 접지 저항 | 0.1 Ω 이하 |
| 카메라 포트 색상 | 표와 일치 |
| 커넥터 체결 | 모든 포트 잠금 확인 |
| 케이블 고정 | 300 mm 이하 간격 |
| 공구·부품 잔류 | 트렁크·엔진룸 내 없음 |

마지막 항목을 반드시 확인하십시오. 남은 공구가 주행 중 이동하면 소음과 손상의 원인이 됩니다.
