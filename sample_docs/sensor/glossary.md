# 용어 찾아보기

이 문서에 나오는 용어와 약어입니다. 하드웨어 작업에는 익숙하지만 센서·네트워크 분야는 처음인 독자를 기준으로 풀어 썼습니다.

## 센서와 광학

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 라이다 | LiDAR (Light Detection and Ranging) | 레이저를 쏘고 돌아오는 시간을 재서 거리를 측정하는 센서. 주변을 점의 집합으로 그려 냅니다 |
| 포인트 클라우드 | point cloud | 라이다가 만들어 내는 점의 집합. 각 점은 좌표와 반사 강도를 가집니다 |
| 포인트 생성률 | point rate | 초당 만들어 내는 점의 개수. 높을수록 조밀한 형상을 얻습니다 |
| 광학창 | optical window | 라이다 전면의 투명 덮개. 레이저가 통과하는 창이며, 오염되면 측정 거리가 줄어듭니다 |
| 시야각 | FoV (Field of View) | 센서가 한 번에 볼 수 있는 각도 범위 |
| Class 1M | Class 1M | IEC 60825-1의 레이저 안전 등급. 맨눈으로는 안전하지만 **확대 광학 기기로 보면 위험**합니다 |
| 반사 강도 | intensity | 되돌아온 레이저의 세기. 표면의 재질과 색에 따라 달라집니다 |

## 장착과 기구

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 브래킷 | bracket | 센서를 차체에 고정하는 금속 받침. 차종마다 형상이 다릅니다 |
| 허용 오차 | tolerance | 설계값에서 벗어나도 되는 범위. `18 N·m ± 2`는 16~20 N·m을 뜻합니다 |
| 조임 토크 | tightening torque | 볼트를 조이는 힘의 크기. 단위는 N·m(뉴턴미터)입니다 |
| 대각선 조임 | cross tightening | 볼트를 마주 보는 순서로 번갈아 조이는 방법. 한쪽이 먼저 밀착되어 기울어지는 것을 막습니다 |
| 하네스 | harness | 여러 전선을 하나로 묶은 다발 |
| 동축 케이블 | coaxial cable | 가운데 심선을 금속 그물이 감싼 케이블. 바깥 그물이 전자파를 막아 주어, 고속 영상을 긴 거리로 보내도 화질이 깨지지 않습니다. 이 킷에서는 카메라 영상과 전원을 한 가닥으로 함께 보냅니다 |
| FAKRA | FAKRA | 차량용 동축 커넥터 규격. 색과 걸쇠 모양으로 용도를 구분해 잘못 꽂는 것을 막습니다 |
| A필러 | A-pillar | 앞유리 양옆의 기둥. 커튼 에어백이 들어 있는 경우가 많습니다 |
| IP 등급 | Ingress Protection | 먼지와 물에 견디는 정도. IP67은 일시적 침수까지, IP54는 생활 방수 수준입니다 |

## 전기와 통신

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| GMSL2 | Gigabit Multimedia Serial Link 2 | 카메라 영상을 동축 케이블 한 가닥으로 보내는 차량용 전송 규격. 같은 케이블로 전원도 함께 공급합니다 |
| PTP | Precision Time Protocol (IEEE 802.1AS) | 여러 장치의 시계를 마이크로초 단위로 맞추는 규약. 라이다와 카메라가 같은 순간을 찍게 합니다 |
| 시간 동기화 오차 | time sync offset | 기준 시각과 각 센서 시계의 차이. 클수록 센서 간 데이터가 어긋납니다 |
| 상시 전원 | constant power | 시동과 무관하게 항상 공급되는 전원 |
| 정션 박스 | junction box | 차량 전원이 분배되는 지점 |
| 단락 | short circuit | 전선끼리 직접 닿아 과도한 전류가 흐르는 상태. 발화의 원인이 됩니다 |
| 접지 | ground | 전기 회로의 기준점. 차량에서는 차체가 접지 역할을 합니다 |
| CCU | Central Computing Unit | 차량의 중앙 연산 장치. VELA OS가 구동되는 컴퓨터입니다 |
| 존 ECU | zonal ECU | 차량을 전방·후방·좌측·우측 구역으로 나눠 각 구역의 장치를 담당하는 제어기 |

## 캘리브레이션

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 캘리브레이션 | calibration | 센서가 실제로 어디에 어떤 각도로 붙었는지 측정해 소프트웨어에 알려 주는 작업 |
| 외재 파라미터 | extrinsic parameters | 센서의 **위치와 방향** 값. 차량 기준점에서 얼마나 떨어져 어느 각도로 놓였는지를 나타냅니다 |
| 내재 파라미터 | intrinsic parameters | 렌즈 왜곡 등 **센서 자체의 특성** 값. 공장에서 측정되어 모듈에 저장됩니다 |
| 정적 캘리브레이션 | static calibration | 차량을 세워 두고 타깃 보드를 이용해 수행하는 방식 |
| 동적 캘리브레이션 | dynamic calibration | 주행하면서 주변 구조물을 이용해 보정하는 방식 |
| 타깃 보드 | target board | 흑백 격자가 인쇄된 판. 센서가 기준점으로 삼습니다 |
| 재투영 오차 | reprojection error | 라이다 점을 카메라 영상 위에 겹쳤을 때 어긋나는 정도. 합격 기준의 핵심 지표입니다 |
