# 용어 찾아보기

이 문서에 나오는 차량 도메인 용어와 약어입니다. 웹·서버 개발 경험은 있지만 차량 분야는 처음인 독자를 기준으로 풀어 썼습니다.

API 파라미터와 필드의 뜻은 각 장의 표에, 에러 코드는 [레퍼런스](./reference.md#에러-코드)에 있습니다.

## 차량 구조

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| CCU | Central Computing Unit | 차량의 중앙 연산 장치. VELA OS가 구동되며, 클라우드와 통신하는 유일한 지점입니다 |
| 존 ECU | zonal ECU | 차량을 전방·후방·좌측·우측 구역으로 나눠 각 구역의 장치를 담당하는 제어기. API의 `zone`이 이 구역입니다 |
| 존 아키텍처 | zonal architecture | 기능별이 아니라 **위치별**로 제어기를 두는 설계. 배선이 짧아지고 무게가 줄어듭니다 |
| 자동차용 이더넷 | automotive Ethernet | 차량 내부에서 쓰는 이더넷. 일반 이더넷보다 선이 적고 전자파 간섭에 강합니다 |
| 텔레매틱스 | telematics | 차량과 외부 서버 사이의 무선 통신 전반 |
| VIN | Vehicle Identification Number | 차량 고유 식별 번호. 이 API에서는 `vehicle_id`를 쓰고 VIN은 직접 노출하지 않습니다 |

## 업계 구조

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| OEM | Original Equipment Manufacturer | 완성차 회사. 현대·기아·테슬라처럼 차를 만들어 파는 회사입니다 |
| Tier 1 | Tier 1 | OEM에 직접 부품이나 소프트웨어를 납품하는 공급사. VELA가 여기에 해당합니다 |
| Tier 2 | Tier 2 | Tier 1에 납품하는 공급사 |
| SDV | Software Defined Vehicle | 차량의 기능이 하드웨어가 아니라 소프트웨어로 결정되는 구조. 출고 후에도 기능이 추가됩니다 |

## 소프트웨어 배포

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| OTA | Over-The-Air | 차량을 정비소에 들이지 않고 무선으로 소프트웨어를 갱신하는 방식 |
| 캠페인 | campaign | 하나의 패키지를 정해진 대상 차량에 배포하는 단위. API 리소스 `campaign`입니다 |
| 타깃 그룹 | target group | 배포 대상 차량의 조건. 차종·하드웨어 구성·현재 버전으로 정의합니다 |
| 롤아웃 | rollout | 대상을 단계적으로 넓혀 가는 배포 방식 (예: 1% → 10% → 100%) |
| 게이트 | gate | 다음 단계로 넘어갈지 판정하는 기준. 성공률과 오류율로 정의합니다 |
| 롤백 | rollback | 배포한 소프트웨어를 이전 버전으로 되돌리는 것 |
| 패키지 | package | 차량에 설치되는 소프트웨어 묶음. 서명이 검증되어야 배포됩니다 |

## 통신과 인증

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| mTLS | mutual TLS | 서버와 클라이언트가 **서로** 인증서를 확인하는 방식. 차량과 클라우드 사이에 쓰입니다 |
| 클라이언트 자격 증명 | client credentials | 사람의 로그인 없이 애플리케이션이 자기 자격으로 토큰을 받는 OAuth 2.0 흐름 |
| 스코프 | scope | 토큰에 허용된 권한의 범위 |
| 웹훅 | webhook | 서버가 이벤트 발생 시 등록된 주소로 요청을 보내는 방식. 폴링의 반대입니다 |
| 서명 검증 | signature verification | 받은 웹훅이 정말 VELA가 보낸 것인지 확인하는 절차 |
| 멱등성 | idempotency | 같은 요청을 여러 번 보내도 결과가 한 번 보낸 것과 같은 성질 |
| 레이트 리밋 | rate limit | 일정 시간 안에 보낼 수 있는 요청 수의 상한 |

## 센서

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 라이다 | LiDAR | 레이저로 거리를 재서 주변을 점의 집합으로 그리는 센서 |
| 캘리브레이션 | calibration | 센서가 실제로 어디에 어떤 각도로 붙었는지 측정해 소프트웨어에 알려 주는 작업 |
| PTP | Precision Time Protocol | 여러 센서의 시계를 마이크로초 단위로 맞추는 규약. `sensor.time_sync.offset`이 이 오차입니다 |
| 진단 스냅숏 | diagnostic snapshot | 특정 시점의 센서 원시 데이터 묶음. 문제 분석에 씁니다 |

자세한 센서 용어는 [VELA Sense 설치 가이드 · 용어 찾아보기](../sensor/glossary.md)에 있습니다.

## 시그널

| 용어 | 영문 | 설명 |
| --- | --- | --- |
| 시그널 | signal | 차량이 보고하는 데이터 항목 하나 (예: `battery.soc`) |
| 시그널 카탈로그 | signal catalog | 사용 가능한 시그널의 전체 목록. [레퍼런스](./reference.md#시그널-카탈로그)에 있습니다 |
| SoC | State of Charge | 배터리 잔량. 백분율로 표시합니다 |
| 보고 주기 | reporting interval | 차량이 해당 시그널을 올려 보내는 간격 |
| 최신값 | latest value | 차량이 마지막으로 보고한 값. 현재 값이 아닙니다 |
