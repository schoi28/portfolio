# VELA Deploy 운영 가이드

:::note[참고]
이 페이지는 제품 문서가 아니라, 그 문서를 어떻게 설계했는지에 대한 기록입니다. 실제 매뉴얼은 다음 장부터 시작합니다.
:::

## 어떻게 설계했나

| 설계 기준 | 결정 |
| --- | --- |
| **핵심 독자** | 차량 소프트웨어 배포를 실행·관리하는 릴리스 운영자 |
| **사전 지식** | 업무용 콘솔과 릴리스 개념에 익숙하지만 코드 사용은 전제하지 않음 |
| **읽는 상황** | 평소에는 절차를 따르고, 장애 시에는 해당 조치를 즉시 찾아봄 |
| **설계 방향** | 배포 캠페인의 생애주기를 따라 구성하고 판단 기준을 빠르게 찾도록 함 |

### 캠페인 진행 순서대로 목차 구성하기

1장에는 배포에 필요한 개념을 모으고, 이후 장은 **캠페인 생성부터 운영·종료까지**의 순서로 배치했습니다. 작업 절차 사이에 긴 개념 설명이 끼어들지 않도록 하기 위해서입니다.

상태 값 등 반복해서 찾는 정보는 [레퍼런스 찾아보기](./reference.md)로 분리했습니다. 머리말은 문서의 대상과 읽는 방법을 안내하고, 1장은 운영 중 다시 확인할 제품 개념을 설명하도록 역할을 나눴습니다.

### 사고 대응을 독립적으로 읽을 수 있게 만들기

장애가 발생했을 때 운영자는 앞 장을 차례대로 읽지 않습니다. 그래서 [문제에 대응하기](./incident-response.md)는 필요한 개념을 그 자리에서 다시 설명해 **이전 장을 읽지 않아도 조치를 찾을 수 있도록** 설계했습니다. 이 경우에는 의도적으로 설명의 중복을 허용했습니다.

### 판단 기준을 표와 참조 정보로 제공하기

'오류율이 높으면 중단'처럼 해석이 필요한 설명 대신 **수치와 조치를 함께 볼 수 있는 표**로 판단 기준을 제시했습니다. 수치는 조직마다 다르므로 예시임을 명시했습니다.

로그에서 확인하는 `in_progress` 같은 상태 값은 레퍼런스에, 개념어는 [용어 찾아보기](./glossary.md)에 두어 찾는 목적에 따라 분리했습니다. 되돌리기 어려운 배포 결정에는 '경고'를 사용했습니다.

## 이 매뉴얼의 머리말

위 판단을 적용해 만든 머리말입니다. 실제 매뉴얼에서는 아래 내용이 1장 앞에 놓입니다.

### 이 문서에 대해

VELA Deploy는 차량 소프트웨어를 단계적으로 배포하고, 문제가 생기면 되돌리는 운영 콘솔입니다. 이 문서는 캠페인을 만들고 운영하고 종료하기까지의 전 과정을 다룹니다.

| 구분 | 내용 |
| --- | --- |
| 다루는 것 | 패키지 업로드 · 타깃 그룹 · 캠페인 생성 · 단계적 롤아웃 · 게이트 판정 · 롤백과 긴급 중단 · 감사 로그 |
| 다루지 않는 것 | 패키지를 만드는 빌드 과정 · 같은 작업의 API 수행(→ [VELA Vehicle API · OTA 배포 제어하기](../api/ota.md)) · 차량 쪽 설치 동작 |
| 적용 버전 | VELA Deploy 2.4 |

### 대상 독자

배포를 실제로 집행하는 릴리스 운영자를 기준으로 썼습니다. **코드를 읽을 수 있다고 전제하지 않습니다.**

| 역할 | 하는 일 | 먼저 읽을 곳 |
| --- | --- | --- |
| **릴리스 운영자** | 캠페인을 만들고 단계를 올린다 | [VELA Deploy란](./overview.md) → [첫 캠페인 만들어 보기](./first-campaign.md) |
| **릴리스 책임자** | 배포 범위를 승인하고 중단을 결정한다 | [롤아웃 운영하기](./rollout.md) · [문제에 대응하기](./incident-response.md) |
| **품질·규제 담당자** | 배포 이력을 증빙으로 제출한다 | [감사 기록 관리하기](./audit.md) |
| **자동화 담당 개발자** | 같은 작업을 API로 수행한다 | [VELA Vehicle API · OTA 배포 제어하기](../api/ota.md) |

전제하는 지식은 다음과 같습니다.

- 업무용 웹 콘솔을 다룰 수 있을 것
- 버전 번호와 릴리스 노트의 개념을 알고 있을 것
- 백분율로 표시된 비율을 읽고 판단할 수 있을 것

**차량 전장 구조나 무선 업데이트의 내부 동작은 전제하지 않습니다.** 필요한 개념은 [VELA Deploy란](./overview.md)와 [용어 찾아보기](./glossary.md)에서 설명합니다.

### 표기 규약

#### 안내 상자

| 등급 | 이 문서에서 쓰는 경우 |
| --- | --- |
| **경고** | 긴급 중단, 롤백 불가 조건, 되돌릴 수 없는 결정 |
| **주의** | 조건 설정 실수, 일시 중지의 범위 오해, 복구 가능한 오류 |
| **참고** | 판단에 참고할 배경 정보 |

신체 위험을 직접 다루지 않으므로 **'위험' 등급은 사용하지 않습니다.** 대신 되돌리기 어려운 배포 결정에 '경고'를 적용합니다.

#### 글자 표기

| 표기 | 뜻 |
| --- | --- |
| **굵은 글씨** | 콘솔 화면에 표시된 요소의 이름 |
| **패키지 > 새 패키지** | 메뉴를 차례로 선택하는 경로 |
| `in_progress` | 시스템이 기록하는 상태 값. 화면에는 한국어로 표시됩니다 |

본문의 숫자 기준(성공률, 대기 시간 등)은 **예시**입니다. 조직의 위험 허용 수준에 따라 정해야 합니다.
