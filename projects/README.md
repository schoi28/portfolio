# Portfolio

사이트의 **Portfolio** 탭 원본입니다. 실무 경력을 프로젝트 단위로 적은 6편입니다.

```
intro.md          탭 개요. 프로젝트 다섯 개의 목록
solution-docs.md  통합 솔루션 문서 세트 신규 구축
build-tooling.md  문서 빌드·검수 도구 자체 개발
docs-as-code.md   문서 운영 체계 수립과 docs-as-code 전환
dbms-manuals.md   DBMS 제품 매뉴얼 운영과 영문화
vela.md           가상 제품군 VELA 문서 세트
```

각 편은 **어려웠던 점 → 해결 방법 → 산출물 → 결과** 순서로 씁니다.

현재 직장의 문서와 코드는 대외비라 공개하지 않습니다. 회사 이름도 적지 않습니다.
공개된 저장소에서 확인할 수 있는 것은 `dbms-manuals.md` 의 Altibase 작업뿐입니다.

영문판은 `i18n/en/docusaurus-plugin-content-docs-projects/current/` 에 있습니다.
