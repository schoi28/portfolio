# 문서 품질 기준

문서를 "잘 썼는가"를 사람마다 다르게 판단하지 않도록, 기준을 여기 모았습니다.
`scripts/check-docs.mjs` 가 이 파일들을 읽어 검사합니다.

**기준과 검사 기능을 나눈 이유**는 제품이나 독자가 바뀔 때
검사기를 고치는 대신 설정만 바꾸기 위해서입니다.

| 파일 | 담은 것 |
| --- | --- |
| `glossary.csv` | 표준 용어 79항목. 쓰지 말 표현과 그 이유 |
| `audience.yaml` | 독자 넷의 사전 지식, 쓰지 않을 용어, 절차 단계 상한 |
| `admonitions.yaml` | 위험 · 경고 · 주의 · 참고의 정의와 문서별 허용 등급 |
| `style-rules.yaml` | 문체, 제목, 표, 이미지, 번역 대조 기준 |
| `diagram-guidelines.md` | 다이어그램 제작 기준. 캔버스 · 색 · 화살표 · 픽토그램 |

## 기계가 보는 것과 사람이 보는 것

금지 표현이 쓰였는지, 링크가 실제로 있는지는 기계가 셉니다.
설명이 이해하기 쉬운지, 그 정보가 독자에게 필요한지는 사람이 판단합니다.

그래서 **검사기가 읽지 않는 항목도 섞여 있습니다.** 각 파일 머리말에 어느 것인지 적어 두었습니다.
